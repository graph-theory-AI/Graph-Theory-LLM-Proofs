Problem. Does every properly edge-colored graph $G$ admit $O(|V(G)|)$ rainbow paths that cover $E(G)$?

Context

This question arose from initial attempts to solve Conjecture 1; a rainbow path is a path containing no two edges of the same color. An affirmative answer would yield an alternative proof of Conjecture 1 via a path decomposition argument, and the authors note that a version with 'trails' replacing 'paths' can already be verified.

=== Source paper abstract / header ===
Abstract:Recently, Letzter proved that any graph of order $n$ contains a collection $\mathcal{P}$ of $O(n\log^\star n)$ paths with the following property: for all distinct edges $e$ and $f$ there exists a path in $\mathcal{P}$ which contains $e$ but not $f$. We improve this upper bound to $19 n$, thus answering a question of G.O.H. Katona and confirming a conjecture independently posed by Balogh, Csaba, Martin, and Pluhár and by Falgas-Ravry, Kittipassorn, Korándi, Letzter, and Narayanan. Our proof is elementary and self-contained.
