Problem. Improve the range of $|S|$ in Theorem 1.

Context

Theorem 1 establishes that if $q$ is an odd prime power and $S\subseteq\mathbb{F}_{q}$ with $0\in S$ and $|S|>(q+1)/2$, then any $A\subseteq\mathbb{F}_{q}^{n}$ containing no three-term arithmetic progression with common difference in $S^{n}$ satisfies $|A|\leq q^{(1-\varepsilon_{q})n}$. The problem asks whether the condition $|S|>(q+1)/2$ can be weakened.

=== Source paper abstract / header ===
Abstract:In this note, we show how to adapt Tao's slice rank method to extend the Ellenberg--Gijswijt theorem on cap sets to the problem of forbidding arithmetic progressions with restricted differences. In particular, we show that if $q$ is an odd prime power, there is $\varepsilon_q>0$ such that if $S \subseteq \mathbb{F}_q$ with $0 \in S$ and $|S|>(q+1)/2$ and $A \subseteq \mathbb{F}_q^n$ contains no three-term arithmetic progression whose common difference is in $S^n$, then $|A| \leq q^{(1-\varepsilon_q)n}$.
