χ-boundedness of radius-1 merge-width graphs — Graph-theory open problems (arXiv)

 
 Status
 open
 high confidence
 

 The source paper (arXiv:2504.08266) proves $\chi$-boundedness for bounded merge-width graphs using radius-2 merge-width in an essential way (Lemma 4.1), but leaves Question 1.4 open: whether the class $\{G : \operatorname{mw}_1(G) \leq k\}$ is $\chi$-bounded for arbitrary $k$. The authors note that a negative answer would require constructing a class with bounded radius-1 merge-width, bounded clique number, and unbounded chromatic number — necessarily containing arbitrarily large bicliques. No follow-up paper resolving this question has been found in the indexed literature as of May 2026.

Question. Is the class $\{G:\operatorname{mw}_{1}(G)\leqslant k\}$, with $k$ arbitrary, $\chi$-bounded?

Context

The proof of $\chi$-boundedness (Theorem 1.2) uses merge-width at radius 2 in an essential way (specifically Lemma 4.1). It is unclear whether radius 1 suffices. A negative answer would require constructing a class of bounded radius-1 merge-width graphs with bounded clique number but unbounded chromatic number; such a class must contain arbitrarily large bicliques.

=== Source paper abstract / header ===
Abstract:Merge-width, recently introduced by Dreier and Toruńczyk, is a common generalisation of bounded expansion classes and twin-width for which the first-order model checking problem remains tractable. We prove that a number of basic properties shared by bounded expansion and bounded twin-width graphs also hold for bounded merge-width graphs: they are $\chi$-bounded, they satisfy the strong Erdős-Hajnal property, and their neighbourhood complexity is linear.
