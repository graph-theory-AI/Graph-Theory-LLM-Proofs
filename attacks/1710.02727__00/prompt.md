Title: Conjecture 4
A minor-closed class of graphs $\mathcal{G}$ satisfies $\mathrm{col}^\star(\mathcal{G}) \leq t$ if and only if there exists $m \geq 1$ such that $K_{t,m} \notin \mathcal{G}$ and $I_{t-1}+P_m \notin \mathcal{G}$.

Context:
Observation 3 shows that any class $\mathcal{G}$ with $\mathrm{col}^\star(\mathcal{G}) \leq t$ can contain only finitely many graphs of the form $K_{t,m}$ or $I_{t-1}+P_m$; the conjecture asserts that this necessary condition is also sufficient for minor-closed classes. Theorem 7 confirms the conjecture for the special case of minor-closed classes of bounded treewidth, and Conjecture 4 would imply $\chi^\star_{\ell}(\mathcal{G}) = \mathrm{col}^\star(\mathcal{G})$ for every minor-closed class.

=== Source paper abstract / header ===
Abstract:The clustered chromatic number of a graph class is the minimum integer $t$ such that for some $C$ the vertices of every graph in the class can be colored in $t$ colors so that every monochromatic component has size at most $C$. We show that the clustered chromatic number of the class of graphs embeddable on a given surface is four, proving the conjecture of Esperet and Ochem. Additionally, we study the list version of the concept and characterize the minor-closed classes of graphs of bounded treewidth with given clustered list chromatic number. We further strengthen the above results to solve some extremal problems on bootstrap percolation of minor-closed classes.
