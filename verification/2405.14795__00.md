# Referee report: 2405.14795__00 (sharp threshold for rainbow stackings)

## Interpretation

Problem 3.1 of Alon–Defant–Kravitz (arXiv:2405.14795, verified against the actual
PDF, p. 10) asks, verbatim: *"Determine whether or not there exists a function
r_0: N -> R such that the following holds. For each n >= 1, let
chi_1, ..., chi_m: ([n] choose 2) -> C_r be independent uniformly random
r-edge-colorings. If r = r(n) satisfies r(n) < r_0(n), then with high probability,
there does not exist a rainbow stacking of chi_1, ..., chi_m. If r = r(n)
satisfies r(n) > r_0(n), then with high probability, there exists a rainbow
stacking of chi_1, ..., chi_m."*  The catalog statement in prompt.md reproduces
this faithfully. The problem is posed in the setting of Theorem 1.1, which fixes
an integer m >= 2; the writeup adopts exactly this reading (every fixed m >= 2,
m = 1 trivial, growing m explicitly excluded in its Section 8). That matches the
intended scope — the follow-up paper by the community (see below) also treats
fixed m. The writeup answers affirmatively, constructing an integer-valued
r_0(n) and using the problem's strict inequalities to leave only r = r_0(n)
unclassified, which is exactly what the problem's phrasing permits. A reasonable
author of the original paper would consider Problem 3.1 resolved by the
statement proven here (modulo the priority issue below). Interpretation: fair,
no strawman, no silent weakening.

Consistency with Theorem 1.1 (checked against the source): the paper proves
nonexistence for r <= mN/(2 log n!) - omega/(log n)^2 and existence for
r >= mN/(2 log n!) + (2m-1)/3 + m/(2 log n) + omega/(log n)^2 (N = C(n,2)). The
writeup's threshold mN/(2 log n!) + (2m-1)/6 + o(1) sits strictly inside this
window, so it contradicts nothing and sharpens the existence side by
(2m-1)/6 + m/(2 log n).

## Reference check

- **arXiv:2405.14795 (Alon, Defant, Kravitz)**: fetched the full PDF. Theorem 1.1
  and Problem 3.1 state exactly what prompt.md and the writeup use, including the
  fixed-m hypothesis, the nonexistence bound r <= mN/(2 log n!) - omega/(log n)^2,
  and the existence bound r >= mN/(2 log n!) + (2m-1)/3 + m/(2 log n) + omega/(log n)^2.
  The writeup's E X formula agrees with the paper's eq. (1), and its weight
  F agrees with the paper's wt(pi) = sum_{k<k'} [C(f_{k,k'},2) + t_{k,k'}]. Confirmed.
- **The writeup cites no external theorems by name**; it uses Whitney's chromatic
  coefficient formula, the Kotecky–Preiss cluster expansion, factorial moments of
  2-cycles, and Cauchy–Schwarz/Paley–Zygmund — all standard, all re-verified here
  (analytically and/or computationally).
- **Priority (FATAL for novelty, not for correctness)**: web search found
  **"The sharp threshold for rainbow stackings of random edge-colourings" by
  Hong Liu, Guorui Ma, Yangrui Xiang, Zhifei Yan, arXiv:2606.31376, submitted
  30 June 2026** (before this verification date, 2026-09-02). Their Theorem 1.1
  proves, for fixed m >= 2: whp no rainbow stacking if
  r <= mN/(2 log n!) + (2m-1)/6 - omega/(log n)^2 and whp a rainbow stacking if
  r >= mN/(2 log n!) + (2m-1)/6 + omega/(log n)^2 — which is exactly equivalent
  to the writeup's mu -> 0 / mu -> infinity criterion (log mu moves by
  Theta(log^2 n) per unit of r). They deduce the exact threshold
  ceil(mN/(2 log n!) + (2m-1)/6) for a density-one set of n, "resolving a problem
  of Alon, Defant and Kravitz". Strikingly, their method is the same as the
  writeup's: second moment + second-order chromatic-polynomial expansion (they
  cite Fadnavis) + spanning-tree decoupling of the permutation interactions. The
  writeup is therefore a rediscovery (or reproduction) of a result already in
  the literature; it deserves no priority, though the coincidence of the
  constant (2m-1)/6 and of the method is strong independent corroboration of
  correctness. The Gu note (Discrete Mathematics 348 (2025) 114261) concerns
  hypergraph analogues of Theorem 1.1 and does not resolve Problem 3.1.

## Caveats

1. **Priority**: the identical theorem (same threshold constant (2m-1)/6, same
   window Theta(1/log^2 n), same fixed-m scope, essentially the same proof
   strategy) appears in Liu–Ma–Xiang–Yan, arXiv:2606.31376 (June 2026). The
   writeup does not mention it. Whether the writeup independently rediscovered
   or reproduced it cannot be determined from the text; either way the result
   is not new.
2. **Fixed m only.** Problem 3.1 is posed in the fixed-m setting of Theorem 1.1,
   so this is the intended scope; but the writeup proves nothing for m = m(n)
   growing (it says so), while the source paper remarks Theorem 1.1 extends to
   slowly growing m.
3. **r = r_0(n) is unclassified**, and r_0 is integer-valued. Both are expressly
   permitted by the problem's strict inequalities; sequences r(n) that equal
   r_0(n) for infinitely many n are covered by neither hypothesis of Problem 3.1.
4. **Standard facts used without citation**: the Kotecky–Preiss cluster-expansion
   coefficient bound (step 4) and the rooted-tree increment bijection. Routine,
   but a journal referee would ask for citations.
5. **Sequence quantification**: "mu_n(r(n)) -> infinity implies P -> 1 for every
   integer sequence r(n)" implicitly uses that all o(1) estimates are along the
   given sequence (Lemma 3 is correctly stated in sequence form); routine
   subsequence bookkeeping, not a gap.
6. Degenerate cases r(n) < m (mu = 0, rainbow stacking impossible) and m = 1
   (trivial) are consistent with the claims; the whole statement is asymptotic
   in n, so small n need no classification.

## Referee summary

I set out assuming this single-pass proof was wrong and failed to break it. Every
lemma survives full re-derivation: the exact encoding of the pair-correlation as
a proper edge-coloring problem on an m-regular bipartite multigraph is verified
by brute force; the second-order chromatic/cluster expansion coefficients, the
line-graph edge and triangle counts, the factorial moments of 2-cycles, the
convexity bound h_k/C(k,2), and the spanning-tree edge probability 2/m are all
verified computationally; the delicate tail estimate in Lemma 3 — the sharp point
where the exponential-moment condition e^{lambda N}/n! = mu^{-1/(m-1)} -> 0 is
used at exactly full strength — checks out line by line. An exact second-moment
computation for m=2 at n up to 50 behaves precisely as the theorem predicts on
both sides of the first-moment root, and the numerically computed thresholds
converge to mN/(2 log n!) + (2m-1)/6. However, the result is not new: Liu, Ma,
Xiang and Yan (arXiv:2606.31376, 30 June 2026) proved the same sharp threshold
with the same constant by essentially the same second-moment/chromatic-expansion/
spanning-tree method, resolving Problem 3.1; their paper independently
corroborates the constant and the criterion. The correct verdict is therefore
ALREADY_KNOWN: the writeup's mathematics is (as far as extensive checking can
tell) correct and would resolve Problem 3.1, but the theorem was already in the
literature before this verification, and the writeup claims novelty it does not
have.
