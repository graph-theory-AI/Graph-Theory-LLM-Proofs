## Interpretation

Question 5.9 of Aboulker–Aubian–Charbit–Lopes, "Clique number of tournaments"
(arXiv:2310.04265), asks — quoting the paper verbatim, confirmed against the v2
full text — "Is there a function ℓ such that, for every tournament T, if
ω⃗(T) ≥ k, then T has a subtournament A such that |A| ≤ ℓ(k) and ω⃗(A) ≥ k?"
Here ω⃗(D) = min over vertex orderings ≺ of the clique number of the backedge
graph D^≺, where uv ∈ E(D^≺) iff u ≺ v and the arc vu ∈ A(D). The writeup uses
exactly this convention (Section 3 of the writeup: with i < j in the ordering,
ij is a backedge iff j → i), so there is no convention mismatch.

The writeup's formalization is the intended one. It refutes the question at
k = 3 by exhibiting, for every n ≥ 3, a tournament T_n on 2n+1 vertices with
ω⃗(T_n) = 3 whose every proper subtournament has ω⃗ ≤ 2; since no bounded
value ℓ(3) can then cover all T_n, no function ℓ exists. This is exactly the
refutation route the source-paper authors themselves anticipated: they state
that Conjecture 5.10 (infinitely many k-ω⃗-critical tournaments) would answer
Question 5.9 negatively, and the writeup in effect proves the k = 3 case of
Conjecture 5.10. A reasonable author of the source paper would consider
Question 5.9 resolved (negatively) by this argument. No interpretation gaming.

One quantifier note: k is implicitly universally quantified in Question 5.9; a
single failing k (here k = 3) suffices to kill ℓ, so the k = 3 refutation is
logically adequate.

| 2. Translations are automorphisms of T_n | VALID | Standard for Cayley digraphs: arcs depend only on differences. |
| 3. Lemma: if every vertex dominates a directed triangle then ω⃗(T) ≥ 3 | VALID | For any ordering, let v be its last vertex; all arcs v→a to out-neighbours are backedges. | 4. Every x ∈ Z_q dominates the directed triangle {x+1, x+2, x+n+1} | VALID | Differences 1, 2, n+1 ∈ S_n (needs n ≥ 3, which is assumed, so that 2 ≤ n-1); triangle arcs have differences 1, n-1, and -(n) ≡ n+1 (mod q), all in S_n. Verified by code for n = 3..60. Hence ω⃗(T_n) ≥ 3. |
| 5. Natural-order backedge graph is the circulant difference graph with D_n = {n} ∪ {n+2,...,2n} | VALID | ij (i<j, d = j-i) is a backedge iff q-d ∈ S_n, i.e. d = n or n+2 ≤ d ≤ 2n. Verified edge-by-edge by code for n = 3..60. |
| 6. That graph's unique triangle is {0, n, 2n}; no K4; hence ω⃗(T_n) ≤ 3 | VALID | If i<j<k form a triangle, a = j-i and b = k-j lie in D_n so a,b ≥ n, while a+b = k-i ≤ 2n; thus a = b = n, forcing i = 0. Also k-i = 2n ∈ D_n (n ≥ 2). Code confirms exactly one triangle and no K4 for n = 3..60. Combined with step 4: ω⃗(T_n) = 3. |
| 7. Restricting the natural order to 1 < ... < 2n shows ω⃗(T_n − 0) ≤ 2 | VALID | Restricting an ordering yields the induced backedge subgraph; the unique triangle used vertex 0, so the restriction is triangle-free. Code confirms triangle-freeness for n = 3..60. |
| 8. Vertex-transitivity gives ω⃗(T_n − v) ≤ 2 for every v | VALID | Follows from step 2. |
| 9. Monotonicity: A ⊆ T implies ω⃗(A) ≤ ω⃗(T); hence every proper subtournament has ω⃗ ≤ 2 | VALID | Restricting the optimal ordering of T to V(A) gives an induced subgraph of the optimal backedge graph. Any proper A avoids some v, so ω⃗(A) ≤ ω⃗(T_n − v) ≤ 2. |
| 10. Disproof of Question 5.9 at k = 3 | VALID | If ℓ existed, pick n with 2n+1 > ℓ(3); the only subtournament of T_n with ω⃗ ≥ 3 is T_n itself, of order 2n+1 > ℓ(3). Contradiction. |

One trivial omission (does not affect the disproof): the writeup calls T_n
"3-ω⃗-critical", which by the source paper's definition requires
ω⃗(T_n − v) = 2 exactly; the writeup proves only ≤ 2. The missing half is
immediate — T_n − v contains directed triangles for n ≥ 3, so ω⃗(T_n − v) ≥ 2
— and my brute force confirms equality for n = 3..7. The disproof itself uses
only the ≤ 2 direction.

## Reference check

- **arXiv:2310.04265 (source paper), v2 of 2026-06-22.** Fetched the full HTML
  text. Question 5.9, Conjecture 5.8, Conjecture 5.10, and the backedge-graph
  definition of ω⃗ all state exactly what the prompt and writeup use, with the
  same convention (edge uv iff u ≺ v and vu ∈ A(D)). The paper knows only the
  trivial critical tournaments (single vertex for k=1, directed triangle for
  k=2) and gives no nontrivial critical families; v2 contains no note that
  Question 5.9 or Conjecture 5.10 has since been resolved.
- **arXiv:2602.09863 (Crew–Fan–Koerts–Moore–Spirkl, Feb 2026).** Fetched. Its
  Corollary 7 is exactly the two-function statement (ω⃗(T) ≥ f(k) implies a
  subtournament of size ≤ ℓ(k) with ω⃗ ≥ k), i.e. Conjecture 5.8, which the
  paper explicitly says it confirms. It does not mention Question 5.9,
  Conjecture 5.10, or critical tournaments, and does not claim f can be the
  identity — so there is no conflict between its "bounded-size certificate"
  abstract phrasing and this disproof.
- **Priority sweep.** Searched for prior resolutions: arXiv:2401.07776
  (Aubian, "Computing the clique number of tournaments") proves deciding
  ω⃗(T) ≤ k NP-complete for k ≥ 3 and refutes Conjecture 4.1 (not 5.9/5.10) of
  the source paper; arXiv:2606.07748 (Aboulker et al., June 2026) and
  arXiv:2608.09710 (Aug 2026) cite the source paper but mention no resolution
  of Question 5.9 or Conjecture 5.10. I found no publication containing this
  construction or any unconditional negative answer to Question 5.9. Note that
  Aubian's NP-completeness already implies a *conditional* negative answer
  (a positive answer to 5.9 would put "ω⃗ ≤ 3" in P by testing all O(n^{ℓ(4)})
  subsets of size ≤ ℓ(4), hence P = NP), so the community had strong reason to
  expect the negative answer; an unconditional disproof via an explicit
  3-critical family nevertheless appears to be new.

- **Independent SAT verification, n = 3..30 (7 to 61 vertices):** encoded
  "there exists an ordering whose backedge graph is triangle-free" as CNF
  (precedence variables + transitivity clauses + one clause per vertex
  triple); kissat reports UNSAT for every T_n (so ω⃗(T_n) ≥ 3 for all
  orderings, matching the Lemma) and SAT for every T_n − 0 (a triangle-free
  ordering exists, so ω⃗(T_n − 0) ≤ 2). All 28 instances complete in ~8 s
  total. No discrepancy of any kind was found.

## Caveats

1. **Criticality half-stated.** "3-ω⃗-critical" formally needs
   ω⃗(T_n − v) = 2, not just ≤ 2; the ≥ 2 half (T_n − v contains a directed
   cycle) is trivial and computationally confirmed, and the disproof only uses
   ≤ 2. Cosmetic.
2. **Range n ≥ 3 is necessary** (the argument uses 2 ∈ S_n, i.e. 2 ≤ n−1); the
   writeup states this hypothesis, so no gap — it merely means the family
   starts at 7 vertices.
3. **Convention dependence.** The proof is tied to the source paper's backedge
   convention (edge iff the arc goes right-to-left in the ordering); the
   writeup matches it exactly. Reversing all arcs / orders gives the same
   parameter, so nothing hinges on this.
4. **Scope vs. claim.** The verdict line says Question 5.9 is disproved; that
   is exactly what is shown. The construction additionally establishes the
   k = 3 case of Conjecture 5.10 but not the full conjecture (k ≥ 4 remains
   open); the writeup does not overclaim this.
5. **Novelty.** The writeup itself flags that literature priority was not
   checked. My sweep (through papers up to Aug 2026 by the same research
   community) found no prior unconditional disproof or any appearance of this
   family; the closest prior art is the P ≠ NP-conditional negative answer
   implicit in Aubian's NP-completeness result (arXiv:2401.07776). I cannot
   fully exclude an unpublished or missed source, but ALREADY_KNOWN is not
   supported by anything I found.

## Referee summary

I set out to break this proof and could not. The construction is a one-line
circulant tweak of the standard rotational tournament (replace difference n by
n+1 in S = {1,...,n}), and every claim about it survives full re-derivation
and independent computation: the last-vertex lemma is airtight, the
natural-order backedge graph analysis is a correct two-line additive argument,
and criticality follows cleanly from vertex-transitivity plus monotonicity.
Exhaustive search over all orderings (n = 3..7) and an independent SAT
encoding (n = 3..30, up to 61 vertices) confirm ω⃗(T_n) = 3 and
ω⃗(T_n − 0) = 2 with zero discrepancies; structural claims were machine-checked
to n = 60. The interpretation matches the source paper verbatim, all citations
check out, and the k = 3 refutation is logically sufficient against the
universally quantified question. The disproof is correct.
