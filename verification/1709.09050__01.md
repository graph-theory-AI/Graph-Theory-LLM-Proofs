## Interpretation

The catalog problem (Bonato–Mohar, arXiv:1709.09050, open problem (1) of Section 5,
restricted to outerplanar graphs) asks: classify which outerplanar graphs are
1-cop-win and which are 2-cop-win, given Theorem 3 (Clarke) that every outerplanar
graph has cop number at most 2.

The writeup answers exactly this question for finite, simple, connected outerplanar
graphs: `c(G) = 1` iff `G` is chordal, else `c(G) = 2`, with an equivalent
block-level characterization (every block on >= 3 vertices is maximal outerplanar,
i.e. has `2n_B - 3` edges) and an explicit reduction of the disconnected case via
`c(G) = sum_j c(G_j)`. This is the intended interpretation — a genuine dichotomy
theorem, not a strawman reading. The standard game model (finite, visible robber,
passing allowed, cop places first) is the one used in the source survey. A
reasonable author of the source paper would consider the conjecture resolved by
this statement. `interpretation_ok: true`.

The writeup itself flags in its caveats that "publication priority was not
independently checked" and sets `would_publish: false`. That caution was warranted:
the classification was already published (see Reference check).

## Step-by-step findings

| step | label | note |
|------|-------|------|
| S1. Statement of the dichotomy (Section "Statement") | VALID | Matches the problem; equivalences among the three formulations are proved in later sections. |
| S2. Lemma 1: 1-cop-win iff dismantlable | VALID | This is the classical Nowakowski–Winkler (1983) / Quilliot (1978) theorem. The given proof is the standard one and is correct: (a) no-corner => robber evades: initial `r \notin N[c]` exists (else every vertex is dominated by `c`, a corner); the invariant `r \notin N[c]` is maintainable because `c' != r` (as `c' \in N[c]`, `r \notin N[c]`) and non-domination gives `r' \in N[r] \setminus N[c']`. (b) The fold `rho` is a retraction since `N[v] \subseteq N[u]`, and cop-win is preserved under retracts (terse here, but classical and correct). (c) Converse shadow-strategy argument is correct: when the shadow is caught with the robber at `v`, the cop sits at `u` and `N[v] \subseteq N[u]` makes every robber move immediately capturable. |
| S3. Lemma 2: no vertex of a hole is ever a corner in an induced subgraph containing the hole (in an outerplanar graph) | VALID | Re-derived in full. `x` is adjacent to `z, a, b` (with `a, b \in N_H[z]` since `H` induced contains all of `C`); `x \notin V(C)` because the only `C`-neighbors of `z` are `a, b` and `x \in \{a, b\}` would force the chord `ab`. The three internally disjoint `a`–`b` paths `a z b` (length 2), `a x b` (length 2), and `Q` (length `|C| - 2 >= 2`) form a subdivision of `K_{2,3}`; outerplanar graphs are `K_{2,3}`-minor-free (Chartrand–Harary; also stated verbatim in the source survey). Independently confirmed by exhaustive computation (check B below, 69,990 cases). |
| S4. Chordal connected outerplanar => 1-cop-win | VALID | A perfect elimination ordering is a dismantling order: a simplicial vertex `v` with neighbor `u` has `N[v] \subseteq N[u]` since `N(v)` is a clique; deleting a simplicial vertex preserves connectedness, so every non-final vertex has a dominating neighbor. Uses only chordal => PEO exists (Dirac / Fulkerson–Gross), standard. (This direction actually holds for all chordal graphs, outerplanarity unused — as the writeup implicitly notes.) |
| S5. Non-chordal outerplanar => not 1-cop-win | VALID | Take a dismantling order, let `v_i` be the first hole vertex removed; `H_i` is an induced subgraph containing all of `C` (the other `>= 3` hole vertices come later, so `i < n` and `v_i` must be a corner of `H_i`), contradicting Lemma 2. Combined with the stipulated `c(G) <= 2` (Theorem 3 of the source, confirmed), `c(G) = 2`. |
| S6. Blocks: `G` chordal iff every block chordal | VALID | Every cycle lies in a single block. |
| S7. 2-connected outerplanar `B` chordal iff maximal outerplanar iff `|E| = 2n - 3` | VALID (one routine detail left implicit) | Hamiltonian outer cycle of a 2-connected outerplanar graph: standard (also quoted in the source survey). The induction "every `n`-cycle in a chordal graph has >= `n - 3` chords" is correct; the count `1 + (p-3) + (q-3) = n - 3` silently uses that the chord sets of the two subcycles are disjoint and exclude the splitting chord — true since the subcycles share only the splitting chord's endpoints — a repairable one-line omission. `|E| <= 2n - 3` is the standard outerplanar edge bound; equality forces edge-maximality. Converse (maximal outerplanar => chordal): a hole would bound an empty interior region in an outerplane embedding, so a diagonal could be added; slightly informal but correct (maximal outerplanar graphs are polygon triangulations, well known to be chordal). Independently confirmed computationally (check A4). |
| S8. Final block-form criterion and linear-time recognition remark | VALID | Follows from S6 + S7; bridge blocks (`K_2`) are trivially chordal. |
| S9. Disconnected case `c(G) = sum_j c(G_j)` | VALID | Standard convention (cops place first); also stated as the working assumption in the source survey ("the cop number is additive on components"). |

## Reference check

1. **"Theorem 3": `c(G) <= 2` for outerplanar graphs.** Confirmed. Fetched
   arXiv:1709.09050 (v2): "Theorem 3 ([16]). If G is an outerplanar graph, then
   c(G) <= 2", credited to N. E. Clarke's doctoral thesis (Dalhousie, 2002). The
   writeup imports this exactly as stipulated by the problem. The survey also
   confirms the problem statement: "the classification of outerplanar graphs which
   are 1- and 2-cop-win remains open" and open problem (1) of Section 5.

2. **Cop-win = dismantlable (Lemma 1).** The writeup proves it from scratch
   (correctly); it is the classical theorem of Quilliot (1978) and
   Nowakowski–Winkler (1983). No misquotation issue.

3. **Outerplanar = {K_4, K_{2,3}}-minor-free.** Confirmed; stated verbatim in the
   source survey (Chartrand–Harary).

4. **Priority — FATAL for novelty.** The exact claimed theorem is already in the
   literature: **Theorem 3.9** of A. Bonato, J. Breen, B. Brimkov, J. Carlson,
   S. English, J. Geneson, L. Hogben, K. E. Perry, C. Reinhart, *Optimizing the
   trade-off between number of cops and capture time in Cops and Robbers*,
   Journal of Combinatorics 13(1) (2022) (arXiv:1903.10087, March 2019):
   "An outerplanar graph G is cop-win if and only if G is connected and chordal."
   I extracted the theorem and its proof from the arXiv PDF. Crucially, that paper
   says explicitly: "This result **resolves an open problem from [4]**", where its
   reference [4] is "A. Bonato, B. Mohar. Topological directions in cops and
   robbers... arXiv/1709.09050" — i.e. precisely the catalog problem under review.
   The result is also cited as known in later work: arXiv:2309.01001 /
   arXiv:2409.16279 (Durocher et al., "Cops and Robbers on 1-Planar Graphs", GD
   2023) cite it as "Bonato et al. showed that an outerplanar graph G is cop-win
   if and only if G is chordal" and generalize it to outer-1-planar graphs
   (their Theorem 5.1). The catalog's auto-review (2026-05) noted the
   "outerplanar + chordal iff 1-cop-win" claim circulating but failed to attribute
   it; the attribution is arXiv:1903.10087, Theorem 3.9.

   (The published proof of the hard direction differs from the writeup's: it gives
   a direct robber escape strategy using that a vertex outside a hole has at most
   two neighbors on it in an outerplanar graph, rather than the dismantlability +
   K_{2,3}-subdivision argument. The writeup's proof appears to be an independent
   rediscovery, not a paraphrase.)

## Caveats

- **Novelty (the only real defect).** The theorem, including the exact
  formulation, was published in 2019 and explicitly billed there as resolving this
  very open problem of Bonato–Mohar. The writeup honestly flagged that priority
  was unchecked (`would_publish: false`), but its `verdict: proved` presents as
  new a result that has been known for seven years. The catalog status "open,
  high confidence" (auto-review 2026-05) is wrong.
- The dichotomy `1/2` as stated needs `G` connected; the writeup states
  connectedness explicitly and handles the disconnected case via component
  additivity (a convention-dependent but standard fact, and the same convention
  the source survey adopts).
- Trivial cases: `K_1` (and `K_2`) are chordal and 1-cop-win; blocks that are
  bridges are exempted from the `2n - 3` count by the ">= 3 vertices" clause —
  all consistent.
- Minor implicit details, all routine: chord-set disjointness in the `n - 3`
  chord count (S7); "retracts preserve cop-win" invoked tersely in Lemma 1;
  the embedding argument that a hole in a maximal outerplanar graph bounds an
  empty region. None affects correctness.
- The proof of the chordal direction never uses outerplanarity (chordal => cop-win
  holds generally); the hard direction uses only `K_{2,3}`-topological-minor
  freeness, as the writeup itself observes — the argument actually proves the
  stronger statement that no graph with a hole and no `K_{2,3}`-subdivision is
  cop-win. This is a feature, not a bug (and matches the outer-1-planar
  generalization already published by Durocher et al.).

## Referee summary

The writeup's mathematics is correct. Every step checks out under detailed
scrutiny: the dismantlability characterization is the classical
Quilliot/Nowakowski–Winkler theorem, correctly proved; the key Lemma 2 (a hole
vertex can never become dominated in a `K_{2,3}`-subdivision-free graph) is sound
and was verified exhaustively by computer; the dichotomy and the block edge-count
characterization were confirmed by brute force against an independent exact game
solver on all 86,356 connected outerplanar graphs with up to 8 vertices, with
perfect agreement. The single imported result (`c <= 2` for outerplanar graphs)
is exactly Theorem 3 of the source survey (Clarke, 2002). However, the theorem is
not new: it is Theorem 3.9 of Bonato, Breen, Brimkov, Carlson, English, Geneson,
Hogben, Perry, Reinhart (arXiv:1903.10087, J. Combinatorics 13(1), 2022), which
explicitly states that it resolves this open problem from the Bonato–Mohar survey,
and it has since been generalized to outer-1-planar graphs (Durocher et al., GD
2023). Verdict: **ALREADY_KNOWN** — a correct, apparently independent
rediscovery of a published result; the catalog entry should be updated to
"resolved by arXiv:1903.10087, Theorem 3.9".
