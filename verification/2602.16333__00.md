# Referee report: 2602.16333__00

**Target.** Conjecture 4.1 of arXiv:2602.16333 (Bucić, Hendrey, Mohar, Steiner,
Yepremyan, *Long cycles in vertex transitive digraphs*): there exist ε > 0 and
infinitely many n for which some connected vertex-transitive digraph of order n
has perimeter gap (order minus circumference) at least εn.

**Writeup's claim.** Proved, with ε = 1/12: for every m ≥ 3 the Cayley digraph
Γ_m = Cay(A4 × Z_m, {u, v}) with u = ((12)(34), 1), v = ((243), 1) is a
strongly connected vertex-transitive oriented digraph on 12m vertices with
circumference at most 11m, via (i) a parity lemma (every bijection f of A4 with
f(x) ∈ {xa, xb} is an even permutation of the 12 group elements), (ii) the
layer structure forcing every directed cycle length to be divisible by m, and
(iii) the fact that a Hamilton cycle would induce a 12-cycle (odd) on layer L_0
as a composition of m even bijections.

## Interpretation

The interpretation is exactly right. I downloaded the full TeX source of
arXiv:2602.16333 and checked:

- The first conjecture in Section 4 ("Concluding remarks") reads verbatim:
  "There exists an ε > 0 and infinitely many values of n for which there exists
  a connected vertex transitive digraph of order n, whose perimeter gap is at
  least εn." This matches the catalog statement and the writeup's
  formalization word for word.
- The paper defines the perimeter gap as "the difference between the number of
  vertices and the length of the longest directed cycle in a digraph", i.e.
  gap(D) = |V(D)| − circ(D), exactly as the writeup uses it.
- The paper's Notation section states that for vertex-transitive digraphs,
  connectedness of the underlying graph and strong connectivity coincide, so
  the writeup's "strongly connected" satisfies the paper's "connected".
- The conjecture asks for infinitely many n (not all n); n = 12m for m ≥ 3
  supplies infinitely many orders.

There is no interpretation gaming: a resolution of this statement is what the
source authors intended (they write that improving their logarithmic bound
"to a polynomial one" would already be interesting; a linear bound resolves the
conjecture outright). No strawman reading is involved.

## Reference check

- **Source conjecture** (arXiv:2602.16333): fetched the abstract page and the
  full arXiv TeX source (main.tex, submitted 2026-02-18). The conjecture,
  the definition of perimeter gap, and the connected/strongly-connected
  equivalence are exactly as the writeup assumes. Confirmed the paper itself
  only proves a (1−o(1))·ln n gap (Theorem 1.1, via Cartesian products of
  directed cycles, prime-partitionable numbers and Motohashi's theorem) and
  Ω(n^{1/3}) circumference (Theorem 1.2).
- **Internal references**: the writeup is self-contained; the only external
  facts used are that ⟨(12)(34), (123)⟩ = A4 (verified by machine) and that a
  generating set of a finite group generates it as a semigroup (standard).
- **Priority — this is the decisive finding.** Bowen Li and Abhishek Methuku,
  "Long Directed Cycles in Vertex-Transitive Digraphs", arXiv:2607.05807
  (v1 posted 2026-07-07, v2 2026-08-19), *already resolves this exact
  conjecture with the identical constant*: their Theorem 1.3 states that for
  infinitely many n there is a connected vertex-transitive digraph on n
  vertices with perimeter gap at least n/12. Their construction is a
  cyclically layered digraph on X × Z_m where X is the set of ordered pairs of
  distinct elements of [4] (|X| = 12), with arcs (a,b,t) → (b,c,t+1),
  c ∉ {a,b}, and their proof uses the same parity obstruction (each layer
  transition is an even permutation of the 12-element layer, while a Hamilton
  cycle would require an odd 12-cycle). They also improve the circumference
  lower bound to Ω(√n). The attack that produced this writeup ran on
  2026-08-31 (per meta.json), roughly eight weeks after Li–Methuku appeared;
  the catalog's "open" status was auto-reviewed on 2026-05-14 and was stale.
  I checked by machine that the writeup's Γ_3 and Li–Methuku's 36-vertex
  digraph are *not* isomorphic (isomorphism.py), so the writeup's digraph is a
  different witness — but the theorem proved, the value ε = 1/12, the order
  12m, and the parity mechanism coincide with the published result.

## Caveats

- **The result is not new.** Conjecture 4.1 was resolved, with the same
  constant ε = 1/12 and the same parity mechanism, by Li and Methuku
  (arXiv:2607.05807) on 2026-07-07, before the attack ran (2026-08-31). The
  writeup's own caveat field ("priority beyond the supplied literature review
  has not been independently checked") anticipated exactly this; the supplied
  catalog review predated Li–Methuku by two months.
- The construction only produces orders n ≡ 0 (mod 12); this is fine, as the
  conjecture asks for infinitely many n, not all n.
- The restriction m ≥ 3 is needed only for the cosmetic claims (loopless,
  no digons); the gap bound itself holds for every m ≥ 1 (machine-checked at
  m = 1).
- The writeup uses the right-to-left permutation-multiplication convention and
  a right Cayley digraph; the conclusion is convention-independent (the
  left-multiplication variant was also machine-checked non-Hamiltonian).
- The claimed circumference bound is stated as circ ≤ 11m (an inequality);
  for m = 3 it is in fact tight (circ = 33), so the gap bound n/12 is exactly
  attained there and cannot be improved for this digraph at m = 3.
