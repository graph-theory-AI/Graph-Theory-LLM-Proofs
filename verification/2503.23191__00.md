## Interpretation

The catalog statement is a verbatim copy of **Question 5.1 of arXiv:2503.23191v1**
(29 Mar 2025): *"Is it true that every oriented graph G with δ⁰(G) ≥ k/2 contains
every orientation of the k-edge path, save for the antidirected orientations?"*
I confirmed this wording against the v1 PDF (Section 5, p. 8). The writeup
interprets it exactly as intended: "antidirected" is used with the paper's own
definition ("an oriented path that alternates the direction of its arcs", v1/v2
Section 5 / introduction), containment means injective embedding (paper, Section 2),
and δ⁰ is min over all in- and out-degrees. No interpretation gaming: the
counterexample path P = v0→v1←v2←v3→v4 is genuinely non-antidirected (it contains
the directed subpath v3→v2→v1), and the host graph genuinely has δ⁰ = k/2. The
writeup's `disproved` verdict for the catalog statement is therefore an honest
reading, not a strawman.

However, there is a decisive version issue. On **1 Aug 2026** the authors posted
**v2**, whose Section 5 makes precisely the writeup's observation. v2 defines
*bouncing paths* (height function h: h₀ = 0, hᵢ₊₁ = hᵢ ± 1 per arc direction;
bouncing iff hᵢ ∈ {−1,0,1} for all i and hⱼ = 0 for every even index j — 
equivalently every odd-position vertex is a source or a sink), notes that every
antidirected path is bouncing, states that *"the blow-up construction excludes
precisely the bouncing paths when k is even"*, and restates the question as:

> **Question 5.1 (v2).** *Is it true that every oriented graph G with δ⁰(G) ≥ k/2
> contains every orientation of the k-edge path, except for the bouncing paths
> when k is even?*

The writeup's paths P and P_m are bouncing (verified by code, below), and its
closing paragraph ("this blow-up excludes every orientation in which all
[odd-position vertices] are sources or sinks... the exact-threshold obstruction is
substantially broader than the antidirected orientations alone") is exactly the
bouncing-path observation of v2. So a reasonable author of the original paper would
**not** consider their conjecture resolved: they already noticed this counterexample
class themselves, retracted the v1 wording, and the intended (v2) question remains
open. The writeup disproves a superseded formulation. (The catalog snapshot was
auto-reviewed 2026-05-14, before v2 appeared, which explains the mismatch; the
attack's date relative to 1 Aug 2026 is not recorded, so I cannot rule out that the
observation was independent, but at refereeing time it is in the literature.)

## Caveats

1. **Version mismatch is the whole story.** The catalog statement is v1's
   Question 5.1; the authors themselves replaced it in v2 (1 Aug 2026) after
   observing exactly this bouncing-path obstruction. The writeup resolves nothing
   that is currently open: the live open problem (v2 Question 5.1, and the
   catalog's "intended" question of whether some clean class of exceptions
   characterizes the k/2 threshold) is unaffected, because the counterexample path
   lies in the excluded (bouncing) class.
2. **Even k only.** The counterexample family exists only for even k (parts of
   size k/2 require k even for δ⁰ = k/2 to be witnessed this way, and bouncing
   requires h_k = 0). For odd k the catalog statement is not disproved (and indeed
   for odd k there are no bouncing k-edge paths, consistent with v2 expecting no
   exceptions there). The writeup's verdict line correctly restricts to "every even
   k ≥ 4" but the catalog question quantifies over all k; strictly, the writeup
   disproves the universally-quantified statement, which only needs one k — fine —
   but it leaves the odd-k half of the threshold question open, unremarked.
3. **k = 2 edge case.** For k = 2, δ⁰ ≥ 1 and the two-edge non-antidirected paths
   are the directed ones, contained by Jackson's theorem; the bouncing = antidirected
   coincidence there means the v1 statement is fine for k = 2. Not discussed in the
   writeup; harmless.
4. The writeup's caveat field ("standard definition that an antidirected path has
   alternating arc directions") is accurate and matches the source paper, so the
   disproof cannot be dodged by a definitional quibble.
5. The attack writeup gives no date; if produced before 1 Aug 2026 the observation
   would have been independent of (and simultaneous with) the authors' own, but it
   was in any case never novel relative to the current literature at refereeing time.

## Referee summary

The mathematics is flawless: every step checks out by hand and by exhaustive
computation, and the finite counterexample (balanced C₃ blow-up, parts of size k/2,
vs. the bouncing non-antidirected path f b b f (+ alternation)) genuinely refutes
the catalog statement, which is a verbatim copy of Question 5.1 of
arXiv:2503.23191**v1**. But the source paper's own authors made the identical
observation and published it in **v2** (1 Aug 2026, Section 5): they introduce the
class of *bouncing paths*, note that the (k/2)-blow-up of a directed cycle excludes
precisely the bouncing paths for even k, and restate Question 5.1 to except bouncing
paths rather than only antidirected ones. The writeup therefore disproves a
superseded formulation without resolving the question the authors actually intend
(v2 Question 5.1 remains open), and the result was already in the literature at
refereeing time. Verdict: ALREADY_KNOWN (source: arXiv:2503.23191v2, Section 5),
with high confidence.
