## Interpretation

The catalog statement was checked verbatim against arXiv:1611.03196v1 (fetched via
the arXiv HTML rendering). Conjecture 1.15 there reads exactly as in
`attacks/1611.03196__03/prompt.md`: for every m there is c(m) such that for any
bipartite G and **arbitrary** edge sets E_1,...,E_m (the paper says "any sets of
edges" — no disjointness or partition requirement; I confirmed this from the source
text and its surrounding paragraphs, which explicitly motivate the under-representation
formulation because the over-representation versions fail for non-partitions), G has a
matching S with |S| >= |E(G)|/Delta(G) - c(m) and |S ∩ E_i| <= ceil(|E_i|/Delta(G))
for all i. The writeup formalizes precisely this and proves the existence of c(m)
with the explicit value 32(m+1)^3. This is the intended reading: the conjecture asks
only for existence of some c(m); the authors' further suggestion that c(m) = m/2 may
suffice is a stronger refinement, which the writeup explicitly leaves open (both in
its verdict block and in its Remarks). A reasonable author of the original paper
would consider Conjecture 1.15 as stated resolved by this result, though the sharp
m/2 question remains. No interpretation gaming detected. (Note: in the later
journal/author version of the paper, e.g. fairrep4.pdf, the numbering shifts and
"Theorem 1.15" is a different result about paths; the catalog id refers to the arXiv
v1 numbering, which matches.)

Lemma 1 (proportional interval splitting: r nonatomic measures, share theta, X a union of <= 2r intervals with nu_j(X) = theta*nu_j(I)) | VALID | This is a weakening of the Stromquist-Woodall theorem (J. Math. Anal. Appl. 108 (1985) 241-248), which gives <= r intervals on [0,1] for r nonatomic probability measures and any theta. Non-probability measures normalize (zero measures are trivially split), and rescaling [0,1] to the cell interval is harmless. The writeup's parenthetical "the usual stronger statement gives at most r intervals" is accurate. Reference confirmed (see below). |

| 3. Lemma 2, cycle/cell structure (A* triangle B* is a disjoint union of even alternating cycles a_1 b_1 ... a_s b_s; a_j meets exactly b_{j-1} and b_j) | VALID | Standard for two perfect matchings (no paths can occur). The adjacency pattern (a_j shares a vertex with b_j and with b_{j-1}, cyclically) was verified on every cycle of every random instance. |
| 4. Lemma 2, application of Lemma 1 to the 2d cell measures, giving X = union of <= 4d intervals with exact theta-shares | VALID | 2d measures with piecewise-constant {0,1}-densities on unit cells are nonatomic; Lemma 1 with r = 2d gives <= 4d intervals (Stromquist-Woodall actually gives <= 2d). |
| 5. Lemma 2, midpoint rounding error <= 8d per measure | VALID | X has <= 8d boundary points; only cells properly cut by a boundary point contribute error, each at most the cell's mass <= 1 (labels are in {0,1}); a boundary point at an integer cell boundary cuts no cell. Re-derived: |sum_{j in J} w_l(a_j) - theta * sum_j w_l(a_j)| <= 8d, and the complementary-sum identity gives the same bound for the b-side. |
| 6. Lemma 2, pre-repair bound (1): |w_l(T) - (theta w_l(A*) + (1-theta) w_l(B*))| <= 16d | VALID | w_l(T) = w_l(A* cap B*) + sum_{j in J} w_l(a_j) + sum_{j notin J} w_l(b_j); target has the common term with coefficient theta + (1-theta) = 1; the two rounding errors of step 5 add to <= 16d. Identity verified computationally (check C4). |
| 7. Lemma 2, conflict analysis and repair (only conflicts are b_{j-1}, a_j at cyclic up-transitions j-1 notin J, j in J; deleting a_j at each yields a matching) | VALID | Per cell exactly one of a_j, b_j is selected, so the only doubly-covered vertices are those between b_{j-1} and a_j at up-transitions; each selected a_j has at most one conflict. Verified computationally: after repair, the edge set (plus common edges) is a matching in every one of 4000 random instances with both random and interval-structured J (check C2). |
| 8. Lemma 2, deletion count <= 16d | VALID | The sampled indicator changes <= 8d times linearly (one X-boundary point per change); each cycle whose cyclic transition count exceeds its internal changes consumes at least one internal change, so cyclic transitions <= 8d + 8d = 16d, and up-transitions (= deletions) are at most that. Verified computationally in interval mode (check C3). |
| 9. Lemma 2, conclusion (w_0(C) >= theta w_0(A) + (1-theta) w_0(B) - 32d; w_j(C) <= ... + 32d for j >= 1) | VALID | Each deleted edge lowers w_0 by <= 1, so w_0 loses <= 16d beyond (1); side coordinates only decrease under deletion (the proven +16d is stronger than the stated +32d). Dummy edges have zero labels, so w_l(A*) = w_l(A) and discarding dummies from C changes nothing. |
| 10. Section 3, Koenig decomposition and p in the convex hull | VALID | chi'(G) = Delta(G) for bipartite G (Koenig's line-coloring theorem), so E(G) partitions into D matchings; summing statistic vectors gives p = (1/D) * sum z(M_j') exactly (partition => sum |M_j' cap E_i| = |E_i|). Verified exactly (Fractions) in the end-to-end script. |
| 11. Section 3, Caratheodory reduction to k <= m+2 matchings | VALID | Caratheodory in R^d, d = m+1: p is a convex combination of <= d+1 = m+2 of the z(M_j'). Implemented exactly over rationals in the end-to-end test; k <= d+1 always held and the point p was preserved. |
| 12. Section 4, iterated interpolation and the induction error (j-1)*32d | VALID | With theta = Lambda_{j-1}/Lambda_j one has p_j = theta p_{j-1} + (1-theta) z(M_j) (since lambda_j/Lambda_j = 1-theta). Re-derived: error_j <= theta*(j-2)*32d + 32d <= (j-1)*32d, with base case error_1 = 0. |
| 13. Section 4, bounds (3)-(4) with 32d^2 | VALID | k - 1 <= d, so the accumulated error is <= d * 32d = 32d^2; p_k = p, whose coordinates are |E|/D and |E_i|/D. |

## Reference check

- **Conjecture 1.15, arXiv:1611.03196v1** (Aharoni, Alon, Berger, Chudnovsky,
  Kotlar, Loebl, Ziv, "Fair representation by independent sets"): fetched via
  https://arxiv.org/html/1611.03196v1. The conjecture, its "any sets of edges"
  hypothesis, the m/2 suggestion, and the surrounding under-representation
  motivation all match the prompt and the writeup's formalization verbatim.
- **Stromquist-Woodall, "Sets on which several measures agree", JMAA 108 (1985)
  241-248**: confirmed (ScienceDirect listing plus secondary sources, e.g. the
  Crew-Narayanan-Spirkl "Disproportionate division" paper and Goldberg et al.
  "Consensus division in an arbitrary ratio", ITCS 2023, which state it in exactly
  this form): for n nonatomic probability measures on [0,1] and any alpha in [0,1]
  there is a union of at most n intervals with measure alpha in every measure. This
  covers Lemma 1 (which asks only for 2r intervals).
- **Koenig's line-coloring theorem** (chi' = Delta for bipartite graphs) and
  **Caratheodory's theorem**: textbook results, used with correct hypotheses.
- **Novelty / ALREADY_KNOWN check**: targeted searches ("Conjecture 1.15" +
  fair representation; under-representation matching |E|/Delta) found no paper
  resolving Conjecture 1.15. The closest literature is Othman-Berger, "Almost fair
  perfect matchings in complete bipartite graphs", Discrete Mathematics 347 (2024)
  (the paper the catalog reviewer could not retrieve): it concerns perfect matchings
  of K_{n,n} under partitions with a two-sided fairness spread s(M), proves m = 2, 3
  and a weak m = 4 bound, and cites an unpublished 2014 result giving a
  K_{n,n}-partition analogue with a constant f(m) — related in spirit but strictly
  narrower than Conjecture 1.15 (complete bipartite only, partitions only). The
  catalog's own auto-review (May 2026) also found no resolution. The conjecture
  appears to be genuinely open in the literature.

## Computational check

Scripts in `verification/scripts/1611.03196__03/`:

1. `test_lemma2_construction.py` — the combinatorial core of Lemma 2. 4000 random
   bipartite instances (sides up to 9, all densities), random matchings A, B, the
   writeup's exact dummy extension, cycle/cell decomposition, and both arbitrary and
   interval-induced cell subsets J. Verified: extensions are perfect matchings;
   cycles alternate with the claimed adjacency pattern; after deleting a_j at every
   cyclic up-transition the selection plus common edges is always a matching;
   deletions <= cyclic transitions <= 16d for interval-structured X; the pre-repair
   statistic identity holds for random {0,1}^d labels. Result: **all 4000 instances
   passed all checks.**

2. `test_conjecture_smallcases.py` — statement-level sanity. 587 random instances
   (|E| <= 22, m <= 3, subsets/partitions/overlapping families), brute-force
   branch-and-bound maximization of |S| subject to the ceiling caps. Result:
   **maximum observed deficit |E|/Delta - max|S| was 1/2** (at |E| = 5, Delta = 2,
   m = 2), consistent with the conjecture, with the authors' suggested c(m) = m/2,
   and far inside the writeup's 32(m+1)^3.

3. `test_pipeline_end2end.py` — the full Sections 3-5 pipeline on bipartite
   circulant graphs (n up to 24, D up to 24, m in {1,2,3}) with explicit Koenig
   decompositions: exact rational Caratheodory reduction (k <= m+2 held in all
   trials, point preserved exactly), iterated Lemma-2 interpolation using a
   coordinate-descent search for the union-of-intervals split (per-measure split
   error <= 0.30 achieved; the exactness of the ideal split is the Stromquist-Woodall
   citation, which is the one step code cannot certify), conflict repair, and the
   final ceiling-enforcement deletions. Result: **every intermediate C_j and the
   final S was a valid matching; worst per-step interpolation error observed was 8
   against the allowed 32d >= 64; final deficits were at most 11 against allowed
   bounds 256-2048; all caps |S cap E_i| <= ceil(|E_i|/D) held.**

No computational check failed.

## Caveats

- **Delta(G) >= 1 is implicitly assumed** (the writeup states D >= 1): for an
  edgeless graph |E|/Delta is 0/0; the conjecture is vacuous there under any
  reasonable convention. Not a real gap.
- **E_i subseteq E(G) is implicitly assumed.** The source paper says "any sets of
  edges" (of G); if one perversely allowed E_i to contain non-edges the claim only
  gets weaker (larger ceiling, same intersections). Harmless.
- **The proof is non-constructive** at exactly one point: the Stromquist-Woodall
  split is topological (Borsuk-Ulam-type); the end-to-end script therefore uses a
  numerical search as a stand-in for that one step. Existence, which is all the
  conjecture asks, is unaffected.
- **Lemma 1 is stated slightly informally** ("standard form of the proportional
  continuous necklace-splitting theorem") without naming Stromquist-Woodall; a
  journal version should cite it precisely. The stated 2r bound is safe (true bound r).
- **The sharp question c(m) = m/2 remains open**, as the writeup itself says; the
  verdict block's one-line claim matches what is actually proven (existence of c(m),
  with 32(m+1)^3).
- **Novelty is probable but not certain**: the interpolation-between-matchings trick
  is folklore-adjacent (cf. the unpublished 2014 K_{n,n} result reported in
  Othman-Berger 2024), so an unindexed prior proof cannot be fully excluded; the
  writeup flags this honestly. All searches performed found no prior resolution.
- The multigraph remark (Remark 1) is correct (Koenig's line-coloring theorem holds
  for bipartite multigraphs) but was not needed for the verdict.

## Referee summary

I approached this as a hostile referee and failed to break the proof. Every step
re-derives cleanly: the dummy extension, alternating-cycle cell structure, midpoint
rounding against an exact Stromquist-Woodall split, the conflict-repair bound of 16d
deletions, the theta-weighted induction through at most m+1 interpolation steps, and
the final ceiling-enforcement arithmetic 32(m+1)^2 * (m+1) = 32(m+1)^3 are all
correct as written; the two places where the writeup states weaker constants than it
proves are deliberate slack, not errors. The single non-elementary ingredient
(proportional interval splitting) is a correctly quoted weakening of the
Stromquist-Woodall theorem, which I confirmed against the literature. The
interpretation is exactly the source paper's Conjecture 1.15 (arbitrary edge sets,
existence of c(m)), checked verbatim against arXiv:1611.03196v1. Computationally,
the combinatorial core passed 4000 randomized structural checks, brute force on 587
small instances never produced a deficit above 1/2, and a full implementation of the
pipeline produced valid matchings meeting every claimed intermediate and final bound.
Literature searches found no prior resolution (the nearest work, Othman-Berger 2024,
treats only K_{n,n} partitions). Verdict: CONFIRMED — the conjecture is proved with
c(m) = 32(m+1)^3; the authors' suggested sharp value m/2 remains open.
