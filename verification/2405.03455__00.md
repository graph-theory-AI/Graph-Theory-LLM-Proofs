# Referee report: 2405.03455__00 (ES_l(n) joint dependence on l)

Target: `attacks/2405.03455__00/output.md`
Problem: determine the correct dependence of ES_l(n) on l, where ES_l(n) is the
minimum N such that every N-point planar set contains l collinear points or n
points in convex position (Conlon–Fox–He–Mubayi–Suk–Verstraete, arXiv:2405.03455,
published Comput. Geom. 131 (2026)). The source paper proves
(3l-1)2^{n-5} < ES_l(n) < l^2 2^{n+C sqrt(n log n)} and asks for the correct
l-dependence.

The writeup claims: ES_l(n) <= l * 2^{n+C_1 sqrt(n log n)} for all l, n >= 3, via
the transfer inequality ES_l(n) <= ceil( l (4 ES_k(n))^{(k-1)/(k-2)} ) with k = n,
so that the dependence on l is uniformly linear, matching the source lower bound.

## Interpretation

The catalog problem is exactly the sentence at the end of the source paper's
introduction: "It remains an interesting open problem to determine the correct
dependence of ES_l(n) on l." I verified this sentence verbatim in the arXiv TeX
source (line 127 of `main.tex`). The context makes clear the question is whether
the l^2 in the upper bound can be brought down to match the linear lower bound
uniformly in both parameters (the regime n fixed, l -> infinity was already known
to be Theta(l) via the paper's cups-caps theorem, as the paper itself states).

The writeup's formalization is faithful: it uses the paper's exact definition of
ES_l(n) (at least l collinear, or n in convex position; arbitrary point sets),
imposes no hidden restrictions on l or n, and proves a uniform upper bound
l * 2^{n+C_1 sqrt(n log n)} valid for all l, n >= 3. Combined with the source
lower bound this pins ES_l(n)/l between 2^n/12 and 2^{n+C_1 sqrt(n log n)}
uniformly, i.e., the dependence on l is linear with no restriction on the
relative sizes of l and n. A reasonable author of the source paper would, in my
judgment, consider this a resolution of the stated open problem about the
l-dependence: the remaining gap, 2^{O(sqrt(n log n))}, is a function of n only
and is precisely the same gap that remains open for the classical Erdos-Szekeres
number ES(n) itself (2^{n-2}+1 vs 2^{n+O(sqrt(n log n))}), so it cannot
reasonably be charged to the l-dependence question. There is no interpretation
gaming: the writeup attacks the intended reading and honestly flags what is not
resolved (the n-gap, and possible prior appearance of the trick).

One honest qualification: "determine the correct dependence" read maximally
strictly (e.g., pin down lim ES_l(n)/l for each n, or the exact function) is not
achieved; what is achieved is that the dependence is Theta(l) uniformly. The
writeup's verdict line says exactly this and does not overclaim.

## Step-by-step findings

Steps S1-S11 are the alteration Lemma (Section 1 of the writeup), S12 is the
transfer inequality (Section 2), S13-S17 are the application (Section 3). Every
computation and inequality was re-derived by hand and re-checked by the scripts
described below.

| step | label | note |
|------|-------|------|
| S1. Lemma statement: P an N-set with < l points on every line contains Q with no k collinear, \|Q\| >= (1/4)(N/l)^{(k-2)/(k-1)} | VALID | Proved by S2-S11; also stress-tested empirically on 30 concrete instances (grids, unions of lines, clusters, random sets), always satisfied with large margin. |
| S2. Identity C(s,k) = C(s,2) C(s-2,k-2) / C(k,2) | VALID | Exact identity; verified symbolically (Fraction arithmetic) for all 3 <= k <= 11, k <= s < 60 (check A1). |
| S3. C(s-2,k-2)/C(k,2) <= l^{k-2} for s <= l-1 | VALID | C(s-2,k-2) <= (s-2)^{k-2} <= l^{k-2} and C(k,2) >= 1; verified for k <= 11, l <= 39 (check A2). Degenerate l=3 case: no line has >= k >= 3 points, e = 0, vacuous. |
| S4. sum_L C(s_L,2) <= C(N,2) | VALID | Each pair of distinct points spans a unique line, so the sums of C(s_L,2) over all lines counts each pair at most once. |
| S5. Inequality (1): e <= l^{k-2} sum_L C(s_L,2) < N^2 l^{k-2} | VALID | Follows from S2-S4 and C(N,2) < N^2/2 < N^2. Strictness fine for N >= 2 (and e = 0 <= anything for N < 2). Empirically confirmed on all 30 test instances. |
| S6. Case e < N/2: deleting one vertex per edge leaves an independent set > N/2 >= (1/4)(N/l)^{(k-2)/(k-1)} | VALID | N - e > N/2; and (N/l)^a <= N^a <= N for a = (k-2)/(k-1) in (0,1), N >= 1, l >= 1, so (1/4)(N/l)^a <= N/4 < N/2 (check D). |
| S7. Case e >= N/2: p = (N/2e)^{1/(k-1)} <= 1 | VALID | Immediate from e >= N/2. |
| S8. E[X - Y] = pN - p^k e = pN/2 | VALID | p^k e = p * p^{k-1} e = p * (N/2e) * e = pN/2. Verified symbolically in sympy for k = 3..14 (check B). |
| S9. Some outcome has X - Y >= pN/2; deleting one vertex from each surviving edge leaves an independent set of size >= pN/2 | VALID | Standard first-moment alteration; deletion removes at most Y vertices from the X chosen ones and destroys every contained edge. |
| S10. pN/2 >= (N/2)(1/(2N l^{k-2}))^{1/(k-1)} = 2^{-1-1/(k-1)} (N/l)^{(k-2)/(k-1)} >= (1/4)(N/l)^{(k-2)/(k-1)} | VALID | First inequality from (1); the algebraic identity verified symbolically for k = 3..14 (check C1); 2^{-1-1/(k-1)} >= 1/4 iff 1/(k-1) <= 1, true for k >= 2, verified for k up to 1000 (check C2). Worst case k = 3 gives 2^{-3/2} ~ 0.354 > 0.25. |
| S11. Independent set in H = subset with no k collinear points | VALID | Edges of H are exactly the collinear k-subsets of P; any k collinear points of an independent set would form an edge. |
| S12. Transfer inequality: with M = ES_k(n), r = (k-1)/(k-2), N = ceil(l (4M)^r), every N-set contains l collinear or n in convex position | VALID | If no l collinear, S1 gives Q with no k collinear and \|Q\| >= (1/4)(N/l)^{1/r} >= (1/4)(4M) = M (since N/l >= (4M)^r exactly); any M-point subset of Q contains k collinear (impossible in Q) or n in convex position. Grid-verified for k = 3..14, M and l over wide ranges (check E). Sanity check at k = n = 3: ES_3(3) = 3 (any non-collinear triple is in convex position), the transfer gives ES_l(3) <= 144 l, consistent with the true value ES_l(3) = l. |
| S13. Instantiation (2): ES_l(n) <= ceil( l (4 ES_n(n))^{(n-1)/(n-2)} ) | VALID | k = n >= 3 is a legal choice in S12. |
| S14. Bound (3): ES_n(n) < n^2 2^{n + C_0 sqrt(n log n)} | VALID | The source paper's Theorem 1.1 holds "for each l, n >= 3" (verified in the TeX source), so setting l = n is legitimate; this is the diagonal instance, not a circular use (the transfer consumes it as a black box). |
| S15. Logarithmic estimate: r log2(4M) <= n + C_1 sqrt(n log n), ceiling absorbed | VALID | r (n + 2 log2 n + 2 + C_0' sqrt(n log2 n)) - n <= C_1 sqrt(n log2 n) for an absolute C_1: verified numerically for all n in [3, 20000] plus 10^5, 10^6; e.g., C_0' = 3 needs C_1 ~ 12.18 (worst case at n = 3), including the ceiling factor log2(13/12) (the argument of the ceiling is >= 12, so ceil(x) <= (13/12) x) (check F). Every term beyond n is indeed O(sqrt(n log n)) with an absolute constant since sqrt(n log2 n) >= sqrt(3 log2 3) > 2 for n >= 3. |
| S16. Lower-bound simplification: (3l-1) 2^{n-5} < ES_l(n) implies ES_l(n) > (1/12) l 2^n for l >= 3 | VALID | (3l-1) 2^{n-5} - (1/12) l 2^n = 2^n (l-3)/96 >= 0 (sympy factorization, check G), with equality only at l = 3; strictness then follows from the strict inequality ES_l(n) > (3l-1) 2^{n-5} (the source paper's Theorem 1.2 actually gives ES_l(n) >= (3l-1) 2^{n-5} + 1). |
| S17. Final display (1/12) l 2^n < ES_l(n) <= l 2^{n + C_1 sqrt(n log n)} and the conclusion of uniformly linear dependence on l | VALID | Direct combination of S13-S16. |

No step is a GAP or ERROR. The writeup's "Remaining gap" section is accurate:
the 2^{O(sqrt(n log n))} factor in n is not closed (nor claimed).

## Reference check

All external inputs were fetched and verified against primary sources:

1. **arXiv:2405.03455 (source paper).** I downloaded the TeX source
   (`arxiv.org/e-print/2405.03455`, saved under the scratchpad) and read it in
   full. Verified: (a) the definition of ES_l(n) matches the writeup's usage;
   (b) Theorem 1.1: "There exists C>0 such that, for each l, n >= 3,
   ES_l(n) <= l^2 * 2^{n+C sqrt(n log n)}" — exactly the hypothesis range
   (l, n >= 3) the writeup needs for the diagonal instance l = n; (c) Theorem 1.2:
   "For each l, n >= 3, ES_l(n) >= (3l-1) * 2^{n-5} + 1" — supplying the strict
   lower bound the writeup quotes; (d) the open-problem sentence appears verbatim.
   The paper's own upper-bound proof (positive-fraction cups-caps + simplicial
   partitions) is entirely different from the writeup's argument and produces the
   l^2 via a (l+n)^2 factor per level; nothing in the paper anticipates the
   bootstrap. The catalog notes the paper was published in Computational Geometry
   131 (2026), art. 102218, without revising the open problem.
2. **Novelty scan (citing literature).** Semantic Scholar lists exactly one paper
   citing 2405.03455: Koki Furukawa, "Big convex polytopes or rich hyperplanes",
   arXiv:2501.03645 (2025). I downloaded its TeX source and read the relevant
   sections. Furukawa proves, via a maximal-general-position-subset argument,
   ES_2(l,n) <= (l-3) C(ES(n)-1, 2) + ES(n) ~ l * 4^{n+O(sqrt(n log n))} and
   explicitly writes: "However, this bound is weaker than the one given by Conlon
   et al. unless l is significantly larger than n." So the literature's best known
   bounds remain l^2 * 2^{n+O(sqrt(n log n))} (small l) and l * 4^{n+...} (huge l);
   the writeup's uniform l * 2^{n+O(sqrt(n log n))} appears in neither and is
   strictly stronger than both. The catalog's auto-review (2026-05, three targeted
   searches) also found no resolution; my own searches (Erdos-Szekeres collinear
   linear dependence; general position subset selection) found nothing closer.
3. **Technique provenance.** The Lemma is a standard k-uniform-hypergraph
   alteration (Spencer-type independence bound); its k = 3 case is the classical
   step in the general position subset selection literature (Payne-Wood,
   SIAM J. Discrete Math. 2013, arXiv:1208.5289, use exactly this kind of
   extraction, with sharper tools). This supports correctness; the specific
   bootstrap through the diagonal value ES_n(n) — which is what makes the exponent
   loss (k-1)/(k-2) harmless — is not something I could find anywhere.

No misquoted or nonexistent citation was found; every quoted bound matches its
source with identical hypotheses.

## Caveats

1. **Conditional on the source paper.** The result consumes Theorem 1.1 of
   arXiv:2405.03455 (at l = n) and Theorem 1.2 as black boxes. Both are
   peer-reviewed (Comput. Geom. 131 (2026)); I did not independently referee the
   source paper's own proofs, but its Section 2-4 arguments read plausibly and
   the theorem statements are used exactly as published.
2. **Novelty is surprising and only negatively certified.** A six-author team of
   leading combinatorialists left the l^2 -> l question open, and Furukawa (2025)
   revisited the l-dependence without finding this two-page bootstrap; my
   citation sweep found only that one citing paper. I cannot exclude that the
   observation is folklore or sitting in an unindexed preprint; the writeup
   itself flags exactly this. This affects novelty, not correctness.
3. **What "determine the correct dependence" now means.** The l-dependence is
   pinned to Theta(l) uniformly; the ratio of the two bounds is
   12 * 2^{C_1 sqrt(n log n)}, a function of n alone, and matching the classical
   ES(n) gap. If one insists that "correct dependence on l" includes the exact
   n-dependent coefficient of l, that remains open — but that reading would make
   the problem subsume the classical Erdos-Szekeres conjecture.
4. **Conventions.** "l collinear" means at least l (both paper and writeup);
   n points in convex position means vertices of a convex n-gon (so collinear
   n-tuples do not count); the writeup is consistent throughout. The equality
   case l = 3 in the final lower-bound display needs the "+1" strictness of the
   paper's Theorem 1.2 (or the strict "<" of its abstract), which holds.
5. **Edge cases.** l = 3 or small N make the hypergraph empty and the Lemma
   vacuous-but-true; k = n = 3 gives ES_l(3) <= 144 l against the true value l
   (wasteful but correct); all constants were checked at the worst case n = 3,
   k = 3. No degenerate case breaks any step.
6. The writeup's headline constant 1/12 in the lower display is tight only at
   l = 3 and is inherited from the source construction, not new.

## Referee summary

I set out assuming the writeup was wrong and could not break it. The argument is
a short, fully elementary bootstrap: a textbook alteration lemma extracts, from
any N-point set with fewer than l collinear, a subset of size
(1/4)(N/l)^{(k-2)/(k-1)} with no k collinear; choosing k = n and feeding the
subset into the source paper's own diagonal bound ES_n(n) < n^2 2^{n+C sqrt(n log n)}
makes the exponent loss (n-1)/(n-2) cost only a constant-plus-subexponential
factor, yielding ES_l(n) <= l * 2^{n+C_1 sqrt(n log n)} for all l, n >= 3. Every
identity, inequality, and asymptotic absorption was re-derived and machine-
verified; the source paper's theorems were checked verbatim in the arXiv TeX; the
only citing paper (Furukawa, arXiv:2501.03645) proves a strictly weaker planar
bound and explicitly acknowledges the regime where it loses, confirming the
claimed bound was not in the indexed literature. The interpretation is the
intended one, and the writeup honestly scopes what remains open (the n-gap
common to classical Erdos-Szekeres). Verdict: CONFIRMED, with the caveat that
the result's simplicity relative to the expertise of the source authors makes
independent expert scrutiny and a folklore check advisable before publication.
