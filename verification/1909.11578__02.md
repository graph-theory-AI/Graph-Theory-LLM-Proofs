## Interpretation

The catalog statement is a verbatim quote of the open question in Section 4 of
arXiv:1909.11578 (Eberhard–Kahn–Narayanan–Spirkl, "On symmetric intersecting
families of vectors", CPC 2021). I downloaded the arXiv v4 TeX source and the
published-version PDF (Narayanan's site); both state, identically:

> "it would be very interesting to at least show that there are constants
> c, δ > 0 (possibly depending on k) such that for any symmetric intersecting
> A ⊂ [k]^n, we have log_k |A| ≤ n − c n^δ."

The paper defines (Section 1): A ⊂ [k]^n is *symmetric* iff Aut(A) = {σ ∈ S_n :
σ(A) = A} is a transitive subgroup of S_n; *intersecting* iff any two elements
agree on at least one coordinate. The writeup uses exactly these definitions
(its counterexample is invariant under the cyclic group Z/nZ, which is
transitive), so its caveat about not being invariant under the full symmetric
group is immaterial — transitivity is what the source paper requires. The
target regime is fixed k ≥ 3, n → ∞, which is also the regime the writeup's
asymptotics address. This is not a strawman reading: the Keller–Lifshitz–Marcus
authors read the question the same way (see Reference check — their source
contains the annotation "This contradicts the conjecture they give in the same
section"). A reasonable author of the source paper would consider the question
resolved (negatively) by this construction. Interpretation: fair.

Note the sentence *preceding* the question in EKNS survives the refutation:
the counterexample is itself "set-intersecting" in EKNS's sense (take B = F_n,
ℓ = 1), so the speculation that the largest symmetric intersecting families are
set-intersecting is untouched; what is refuted is the printed quantitative
bound, whose posing appears to be an oversight in EKNS (their own reference [7]
contains the set-family ingredient).

## Step-by-step findings

The writeup: F_n = {S ⊆ Z_n : ℓ(S) > ℓ(S^c)}, ℓ = longest cyclic run;
A_n = {x ∈ [k]^n : {i : x_i = 1} ∈ F_n}; p = 1/k, λ = log(1/(1−p)),
m = ⌈3 log n / λ⌉, γ = 3 log(1/p)/log(1/(1−p)).

| step | label | note |
|------|-------|------|
| 1a. F_n rotation-invariant | VALID | Rotations preserve cyclic intervals of both S and S^c. Verified exhaustively for n ≤ 14. |
| 1b. F_n increasing | VALID | S ⊆ T ⇒ ℓ(T) ≥ ℓ(S) and ℓ(T^c) ≤ ℓ(S^c) (runs of S are runs of T; T^c ⊆ S^c). Verified exhaustively for n ≤ 14. |
| 1c. F_n complement-free | VALID | ℓ(S) > ℓ(S^c) excludes ℓ(S^c) > ℓ(S). Verified exhaustively for n ≤ 14. |
| 1d. F_n intersecting | VALID | Disjoint S,T ∈ F_n would give T ⊆ S^c, so S^c ∈ F_n by 1b, contradicting 1c. Standard argument (increasing + complement-free ⇒ intersecting). All pairs checked exhaustively for n ≤ 12. |
| 2a. m = ⌈3 log n/λ⌉ < n for large n | VALID | m = Θ_k(log n); for k = 3 need roughly n ≳ 60 (m < n); the writeup says "for sufficiently large n", which suffices for the asymptotic contradiction in step 4. |
| 2b. (1−p)^m = e^{−λm} ≤ n^{−3} since m ≥ 3 log n/λ. Re-derived; Monte Carlo at n = 10^3, 10^4, 10^5 found 0 failures in 20 000/20 000/5 000 conditioned samples. |
| 2c. μ_p(F_n) ≥ p^m(1 − n^{−2}) | VALID | On {I ⊆ S} ∩ {ℓ(S^c) ≤ m−1}: ℓ(S) ≥ m > ℓ(S^c), so S ∈ F_n; Pr(I ⊆ S) = p^m. |
| 2d. p^m ≥ p·n^{−γ} | VALID | m ≤ 3 log n/λ + 1 and p < 1, so p^m ≥ p^{3 log n/λ + 1} = p·e^{−(3 log n/λ)log(1/p)} = p·n^{−γ}. Re-derived. |
| 2e. μ_p(F_n) ≥ (p/2)·n^{−γ} for large n | VALID | Needs only 1 − n^{−2} ≥ 1/2 and 2a. |
| 3a. A_n symmetric | VALID | The cyclic shift σ acts by (σx)_i = x_{σ(i)}; supports transform by rotation, F_n is rotation-closed (1a), and Z/nZ ≤ Aut(A_n) is transitive. |
| 3b. A_n intersecting | VALID | x, y ∈ A_n ⇒ supports in F_n ⇒ supports meet (1d) ⇒ ∃i: x_i = y_i = 1. Verified exhaustively for k = 3, n = 4..7 (e.g. all C(323,2) pairs at n = 7). |

## Reference check

- **Source paper statement and definitions** (arXiv:1909.11578): confirmed
  against the downloaded arXiv v4 TeX source and the published-version PDF from
  Narayanan's Rutgers page. The Section 4 question, the definition of symmetric
  (transitive Aut), and the definition of intersecting all match the writeup's
  usage exactly. The writeup invokes no other external result; its proof is
  self-contained. references_ok: true.

Prior-art findings (decisive for the verdict):

- **Ellis–Kalai–Narayanan, "On symmetric intersecting families"**, European J.
  Combin. 86 (2020), arXiv:1702.02607 — reference [7] of the source paper.
  Its Section "Lower bounds for large k" contains *exactly* the runs family:
  F(n,k) = k-subsets of Z_n whose longest run of ones beats the longest run of
  zeros, proved there to be symmetric and intersecting, with the explicit
  remark: "the non-uniform case of this construction, i.e., the family of all
  cyclic strings of n zeros and ones in which the longest run of consecutive
  ones is longer than the longest run of consecutive zeros, shows that the
  Kahn–Kalai–Linial theorem cannot be improved by more than a constant factor
  for intersecting families; see [mathoverflow]" — citing G. Kalai's 2012
  MathOverflow answer (mathoverflow.net/q/105099). The non-uniform family is
  identical to the writeup's F_n. Their published Lemma (l:lbgen) computes
  |F(n,k')| ≥ n·exp(−(1+O(1/log n))·(log n − log k')/(log n − log(n−k'))·log n)
  ·C(n,k') for √n log n ≤ k' ≤ n/2, which at the level k' = n/k (fixed k, large
  n) already gives polynomially small relative size — the density computation
  the writeup redoes in its Section 2.

- **Keller–Lifshitz–Marcus, "Sharp hypercontractivity for global functions"**,
  arXiv:2307.01356 (the paper the catalog's own literature review cites as
  "partial"). In the *active published text*, immediately after their Theorem
  on transitive-symmetric vector-intersecting families (Theorem 1.6 /
  theo:vector_intersecting_upper_bound), they exhibit a transitive-symmetric
  vector-intersecting family A ⊂ [k]^n (lift of tribes ∩ dual-tribes) with
  |A|/k^n = exp(−O(k log k log n)), stating "This construction follows a
  strategy suggested in [EKNS19, Section 4]", and note the analogous
  'longest-run-of-ones' example [EKN17, MO12] in the set setting. For fixed k,
  exp(−O(k log k log n)) = n^{−O_k(1)} is exactly the writeup's conclusion.
  The KLM source even contains the (commented-out) lines: "this constructions
  disprove a conjecture given in [EKNS19, Section 4], for k < n^δ" and the
  author annotation "This contradicts the conjecture they give in the same
  section. Don't we want to write this?" — i.e., the experts knew the EKNS
  Section-4 question is false as stated, though they chose not to print the
  sentence. The catalog's auto-review misread KLM as only partial progress
  (upper-bound side, growing k) and missed that KLM's *tightness example*
  already refutes the fixed-k conjecture.

## Caveats

- **Asymptotic-only refutation**: the contradiction needs n large (for k = 3,
  the bound μ ≥ (p/2)n^{−γ_k} kicks in once m < n and n^{−2} ≤ 1/2, roughly
  n ≳ 60; the writeup honestly says "for sufficiently large n"). Since the
  conjecture is an asymptotic statement (∀n, with fixed c, δ), this is enough.
- The constant γ_k = 3 log k/log(k/(k−1)) ≈ 3k log k is not optimized (true
  decay is ≈ n^{1−log k/log(k/(k−1))}); irrelevant for the refutation.
- The final remark "no universal deficit ω(log n) … is possible" is correct as
  stated (the construction has deficit ≤ γ_k log_k n + O(1)).
- The refutation leaves intact the *other* EKNS Section-4 speculation (largest
  symmetric intersecting families may be set-intersecting): F_n's lift is
  itself set-intersecting. It also does not contradict EKNS Theorem 1.1
  (o(k^n), in fact O(k^n·n^{−c/k})) — the construction's density is polynomially
  small, comfortably o(1).
- Verdict semantics: the mathematical content is fully CONFIRMED (every step
  VALID, computations verified, interpretation fair). I mark ALREADY_KNOWN
  because the counterexample is assembled from published pieces aimed at
  precisely this question: the set-family F_n is verbatim in EKN
  (arXiv:1702.02607, with density analysis; Kalai MO 2012), the lifting
  strategy is EKNS's own Section 4, and KLM (arXiv:2307.01356) publish the
  lifted transitive-symmetric vector family with density exp(−O(k log k log n))
  crediting the EKNS strategy — their source comments explicitly note it
  disproves the EKNS conjecture. What has apparently never been *printed* is
  the one-sentence conclusion for fixed k; the writeup's genuine contribution
  is stating and proving that sentence cleanly. The catalog's "open" status is
  wrong and should be updated to "false as stated / essentially known".

## Referee summary

I set out assuming the writeup was wrong — a single-pass refutation of a
question posed by Eberhard, Kahn, Narayanan and Spirkl looked implausible — and
instead verified it completely. The construction (cyclic strings whose longest
run of 1s beats the longest run of non-1s, lifted to [k]^n on the value 1) is
elementary, and every one of its steps checks out analytically; exhaustive
computation confirms the set family and the lifted vector family are symmetric
and intersecting, and both exact enumeration (n ≤ 24) and Monte Carlo
(n ≤ 10^5) confirm the density is only polynomially small, so
log_k|A_n| = n − O_k(log n), refuting log_k|A| ≤ n − cn^δ. The resolution of
the apparent implausibility is in the literature: the identical set family
appears in Ellis–Kalai–Narayanan (arXiv:1702.02607, cited as [7] by the source
paper) and Kalai's 2012 MathOverflow answer, and Keller–Lifshitz–Marcus
(arXiv:2307.01356) publish the lifted transitive-symmetric vector-intersecting
family of density exp(−O(k log k log n)) "following a strategy suggested in
[EKNS19, Section 4]" — with source-file comments stating outright that it
disproves the EKNS Section-4 conjecture. The question was thus posed by
oversight and its negative answer is essentially known to experts, though
never printed for fixed k; hence ALREADY_KNOWN rather than CONFIRMED, with the
explicit note that the writeup's mathematics is correct in full.
