## Interpretation

The writeup formalizes the game exactly as the source paper does. I fetched
arXiv:2307.15512v2 (Erde, Kang, Lehner, Mohar, Schmid; CJM 77 (2025) 1135-1162)
and confirmed from the paper itself (Section 1, pp. 1-3):

- **Game**: pieces occupy vertices; cops place first, robber second; players
  alternate with cops moving first; a piece may move to any vertex in a common
  hyperedge (or stay); capture = a cop occupies the robber's vertex. This is
  precisely the writeup's convention.
- **2-section equivalence**: the paper states verbatim (p. 3): "Note that by
  replacing every edge in a hypergraph by a clique, we arrive at an equivalent
  2-graph game on the same vertex set. Thus, the game of Cops and Robber on
  hypergraphs is equivalent to the 2-graph game played on a restricted class of
  graphs." So the writeup's Step 1 reduction is the paper's own observation,
  not an interpretive liberty.
- **Conjecture 1.4** (p. 4, verbatim): "Let H be a connected k-graph on n
  vertices. Then c(H) = O(sqrt(n/k))." No restriction on k relative to n. The
  implied constant must be uniform in k: the paper's own deduction that
  Conjecture 1.4 implies Meyniel's conjecture applies it with k = n^alpha,
  alpha < 1, i.e. with k growing with n. The writeup's choice k = Theta(n^{1/2})
  (alpha = 1/2) is squarely inside the intended scope; the paper even singles
  out the regime k >= sqrt(n), d = k as the place where its own upper bound
  carries an unavoidable log n factor (discussion after Theorem 1.6).

A construction with c(H)/sqrt(n/k) -> infinity therefore refutes the conjecture
as intended, not a strawman literal reading. A reasonable author would consider
Conjecture 1.4 as stated disproved (while a weakened Õ(sqrt(n/k)) variant, and
Meyniel's conjecture itself, remain untouched — see Caveats).

## Reference check

- **Conjecture 1.4** (arXiv:2307.15512v2, p. 4): fetched the paper PDF and read
  pp. 1-6. Statement matches the catalog and the writeup verbatim; the constant
  is intended uniform in k (needed for the paper's own Meyniel implication).
- **Game definition / 2-section equivalence**: stated explicitly in the source
  paper (p. 1 for the alternating-move, same-vertex-capture rules; p. 3 for the
  equivalence with the 2-graph game). The writeup's only structural reliance on
  the source checks out exactly.
- **"Standard Chernoff estimates"**: the only external mathematical tool
  invoked; the multiplicative Chernoff lower-tail bound P(X ≤ μ/2) ≤ e^{−μ/8}
  is standard and I re-verified the numerical tails exactly (section E2 of the
  script), which are far stronger than the bound used.
- **Corroboration**: the literature already contains the analogous graph fact —
  for 2 log n/√n ≤ p ≤ 1 − ε, whp c(G(n,p)) = Θ(log n/p) (Bonato-Hahn-Wang for
  constant p; Łuczak-Prałat regime) — i.e., dense random graphs exhibit exactly
  the (n/d)·log n cop number the writeup's R-part supplies. The construction's
  novelty is only the clique attachment making every edge lie in a K_k without
  helping the cops.
- **No prior refutation / no conflict**: the catalog (auto-review 2026-05-15)
  and my searches found no paper resolving Conjecture 1.4. The follow-up
  arXiv:2606.27066 (June 2026) proves c = O(√(n/k)) (no log) for random
  hypergraphs and for (d,α)-expanding k-graphs with k ≥ log³n, d/k ≥ log³n.
  This does NOT conflict with the writeup: its (d,α)-expansion (Definition 2.1,
  Property 2 at r = 1) forces α·d ≤ deg(v) ≤ d/α for all v with constant α,
  while the construction's P-vertices have degree Θ(N) versus Θ(N^{3/4}) for
  R-vertices — a ratio Θ(N^{1/4}) → ∞, so H lies outside every class for which
  the conjecture has been proven. In fact the construction sits exactly at the
  spot (k ≈ √n) where the source paper's own expander bound (Theorem 1.5/1.6)
  retains a log n factor, showing that factor is necessary in general.

## Caveats

1. **The refutation margin is only a log factor.** c(H) = Ω(√(n/k)·log n)
   versus conjectured O(√(n/k)). The big-O statement (uniform constant) is
   genuinely false, but the weakened form c(H) = Õ(√(n/k)) — which is what the
   source paper actually proved for random hypergraphs — is untouched, and the
   Meyniel implication for k = n^α survives in Õ-form. Meyniel's conjecture
   itself (k = 2) is unaffected; the construction is vacuous at bounded k.
2. **Asymptotic, not explicit-instance, refutation.** The full-size cop number
   of a sampled instance cannot be machine-verified (exact cop number
   computation is infeasible beyond ~20 vertices); the disproof rests on the
   union-bound argument, which I re-derived in full. With the writeup's own
   constants, all estimates hold simultaneously for N ≥ 2^15 (n ≥ 65536,
   k = 90, q ≥ 4); at N = 4096 event 𝒜 empirically fails, consistent with the
   bounds. The writeup honestly claims only "sufficiently large N".
3. **Constant-uniformity reading.** The refutation requires reading O(√(n/k))
   with a constant uniform in k. This is unambiguously the intended reading
   (the paper's own Meyniel deduction requires it), but a per-k-constant
   reading would not be refuted by this construction alone (it uses one k per n).
4. **Convention dependence.** Everything assumes capture = same vertex, cops
   place and move first, moves along hyperedges with staying allowed — all
   confirmed against the source paper. Under an exotic "capture = same
   hyperedge" rule the argument would need rechecking, but that is not the
   source's game.
5. **Community status.** As of June 2026 (arXiv:2606.27066) experts still
   treated the general conjecture as open and were proving positive cases; a
   correct refutation this elementary is surprising, though it explains why
   the positive results all require regularity/expansion hypotheses that the
   construction maximally violates, and why the log factor at k ≈ √n resisted
   removal in the source paper.

## Referee summary

I set out to break this writeup and could not. The interpretation is exactly
the source paper's: the game is the standard vertex-occupancy hypergraph
pursuit game, the 2-section reduction is the paper's own stated equivalence,
and Conjecture 1.4 with a k-uniform constant is precisely what the authors
assert (their Meyniel implication depends on that uniformity). The
construction — a clique P of size N glued by density-N^{−1/4} random edges to
a random part R, hyperedges being one K_k per edge with k = ⌊√N/2⌋ — is
elementary, and every one of its fourteen steps checks out: the Chernoff
clique-covering event, the safe-neighbor evasion lemma (which is robust to
adaptive cop play because it quantifies over all position sets of size ≤ q),
the independence structure of the escape events, and the union bound with
exp(O(N^{1/4} ln² N)) configurations against failure probability
exp(−N^{11/16}/2). Machine verification confirmed the game solver semantics,
the lemma, the reduction, the escape-probability formula to three decimals,
and every finite inequality (all simultaneously valid for N ≥ 2^15). The
result coheres with the literature: it transplants the known Θ(log n/p) cop
number of dense random graphs into the hypergraph setting at k ≈ √n, exactly
where the source paper's own upper bound retains a log n factor, and it does
not contradict the 2026 follow-up, whose expansion hypotheses the construction
violates by an unbounded degree ratio. Verdict: the disproof stands.
