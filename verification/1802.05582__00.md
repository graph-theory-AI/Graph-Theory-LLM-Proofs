# Referee report: 1802.05582__00

## Interpretation

The open problem (Aboulker–Bonamy–Bousquet–Esperet, arXiv:1802.05582, Section 1.5) reads, verbatim from the paper (fetched from ar5iv):

> "We also note that using network decompositions, we can replace the O(d^4 log^3 n) round
> complexity in Theorem 1.3 by d^3 2^{O(sqrt(log n))} ... These alternative bounds are not very
> satisfying, and in most of the applications we have in mind d is a constant anyway, so we omit
> the details." — "It remains interesting to obtain a bound on the round complexity that is
> sublinear in n regardless of the value of d."

The task governed by this remark is the paper's Theorem 1.3 (verbatim): *"There is a
deterministic distributed algorithm that given an n-vertex graph G, and an integer
d ≥ max(3, mad(G)), either finds a (d+1)-clique in G, or finds a d-list-coloring of G in
O(d^4 log^3 n) rounds."* The model is deterministic LOCAL with unbounded messages and, the
paper states explicitly, "infinite computational power" at each node; the paper also notes
d ≤ n WLOG. So the intended ask is: a single round bound T(n) = o(n), valid uniformly over all
d ≤ n, for this d-list-coloring task.

The writeup adopts exactly this reading and proves a wrapper theorem: any list-colorable
instance with lists of size ≥ q can be solved in O(n/q + polylog n) LOCAL rounds
(high-degree components have weak diameter O(n/q), are gathered and colored centrally; the
residual low-degree part is a (deg+1)-list-coloring instance solvable in polylog n rounds via
Rozhoň–Ghaffari network decomposition). Balancing against the quoted O(d^4 log^3 n) algorithm
at D = (n/log^3 n)^{1/5} gives O(n^{4/5}(log n)^{3/5}) = o(n) with no d in the bound. This is
a fair, non-gamed interpretation: a reasonable author of the source paper would regard a uniform
O(n^{4/5} polylog n) bound for the Theorem 1.3 task as answering the remark. Notably, the
authors' own aside ("in most of the applications we have in mind d is a constant anyway, so we
omit the details") is consistent with the large-d regime simply not having been pursued; and
the writeup's weaker variant n^{3/4} 2^{O(sqrt(log n))} = o(n) would already have been reachable
with 2018 technology (Panconesi–Srinivasan decompositions), so no anachronism is hidden in the
argument — Rozhoň–Ghaffari only improves the exponent/polylog.

Two deviations from the letter of the source, both flagged by the writeup itself or minor:

1. The writeup's "source-style problem" assumes mad(G) < d strictly (which excludes
   (d+1)-cliques and makes every subgraph (d-1)-degenerate, so the central colorings are
   greedy), whereas Theorem 1.3 allows d ≥ mad(G) with a (d+1)-clique escape clause. The
   general wrapper theorem (list-colorable promise + unrestricted local computation, which the
   paper's model explicitly grants) covers the boundary case too, but the reduction of the full
   either/or task to the promise version — detect (d+1)-cliques in O(1) rounds; if none, the
   source's own Theorem 1.2 ("d = ⌈mad(G)⌉ ≥ 3 and no (d+1)-clique implies ch(G) ≤ d")
   guarantees the promise — is not written out. Routine, but a gap as written.
2. The catalog page's paraphrase ("d-degenerate graphs with (1+ε)d colors") does not actually
   appear in the source paper (the paper works with mad; Barenboim–Elkin is quoted there with
   ⌊(2+ε)a⌋+1 colors for arboricity a). The writeup correctly identifies this paraphrase as
   defective (its d = 1, two-color case is Ω(n)-hard) and correctly reverts to the source
   formulation. This is a point in the writeup's favor, not against it.

## Caveats

- **Scope vs Theorem 1.3 (G1)**: as written, the "source-style" theorem covers mad(G) < d;
  the paper's task allows mad(G) ≤ d with a (d+1)-clique escape. The repair (O(1)-round clique
  detection + the paper's Theorem 1.2 + exhaustive search under the promise) is routine but
  absent from the writeup.
- **Model dependence**: the result is for deterministic LOCAL with unbounded messages and free
  local computation — exactly the source's model, and the writeup says so. It does not
  transfer to CONGEST (gathering a weak-diameter-n/q component is bandwidth-heavy), and in the
  general (non-sparse) promise version the local computation is an exhaustive search.
- **Knowledge of n** (to set the threshold D and the gathering radius) is assumed, as is
  standard for this literature; the writeup does not state it.
- **Polylog additive term**: the final bound O(n^{4/5}(log n)^{3/5}) is sublinear but far from
  polylog; the open problem only asked for o(n) uniform in d, so this is enough, but it is
  worth stating that the "interesting" stronger goals (e.g., d-independent polylog) remain open.
- **Novelty**: unverified, and the writeup says so ("would_publish: false"). The two
  ingredients (RG decomposition; high-degree components have weak diameter O(n/q)) are
  elementary, and the n^{3/4}2^{O(sqrt(log n))} variant was technically reachable in 2018; the
  result may be folklore even though no written source was found. If a source surfaces, the
  correct verdict becomes ALREADY_KNOWN rather than anything worse.
- **Catalog paraphrase**: the catalog's "(1+ε)d colors for d-degenerate graphs" phrasing is not
  in the source paper and is false for d ∈ {1, 2} as literally stated (2-coloring paths is
  Ω(n)); the writeup's Section 6 handles this correctly. The catalog's RG citation id
  (1907.05254) is also wrong (should be 1907.10937).

## Referee summary

I set out to break this writeup and could not. The claimed resolution rests on one genuinely
load-bearing observation — Lemma 2, that the subgraph induced by vertices of degree ≥ q has
components of weak diameter at most 5n/(q+1)+4 in G — plus a standard consequence of
Rozhoň–Ghaffari network decomposition (deg+1 list-coloring in polylog rounds) and an exponent
balance. I re-derived every inequality by hand (they are all correct, and Lemma 2's constant is
even slightly loose in the safe direction), confirmed the source paper's Theorem 1.3, its model
assumptions, and the exact open-problem paragraph against the arXiv text, confirmed the
Rozhoň–Ghaffari result at its correct id (1907.10937 — the catalog's 1907.05254 is a different
paper), and verified Lemma 2, the end-to-end two-phase coloring, the Lemma 1 invariant, and the
balancing numerically (all checks passed, 800+ randomized cases). The interpretation is the
intended one: the paper asks for a single o(n) round bound valid for all d, and
O(n^{4/5}(log n)^{3/5}) delivers it; a reasonable author of the source paper would consider the
remark answered. What keeps this from CONFIRMED is a short list of unwritten routine repairs:
the mad(G) = d boundary of Theorem 1.3 with its clique escape (fixable via the paper's own
Theorem 1.2), standard LOCAL bookkeeping (knowledge of n, canonical-choice consistency), and
the honest but unresolved question of whether this elementary wrapper is folklore. Verdict:
MINOR_GAPS — correct modulo routine repairable details, with an ALREADY_KNOWN risk that no
search could substantiate.
