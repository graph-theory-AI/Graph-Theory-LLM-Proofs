=== Source paper abstract / header ===
Abstract:The "clustered chromatic number" of a class of graphs is the minimum integer $k$ such that for some integer $c$ every graph in the class is $k$-colourable with monochromatic components of size at most $c$. We prove that for every graph $H$, the clustered chromatic number of the class of $H$-minor-free graphs is tied to the tree-depth of $H$. In particular, if $H$ is connected with tree-depth $t$ then every $H$-minor-free graph is $(2^{t+1}-4)$-colourable with monochromatic components of size at most $c(H)$. This provides the first evidence for a conjecture of Ossona de Mendez, Oum and Wood (2016) about defective colouring of $H$-minor-free graphs. If $t=3$ then we prove that 4 colours suffice, which is best possible. We also determine those minor-closed graph classes with clustered chromatic number 2. Finally, we develop a conjecture for the clustered chromatic number of an arbitrary minor-closed class.

## Statement

Under the standard definitions, the asserted inequality
\[
\chi^*(\mathcal M_H)\le 2\,\operatorname{td}(H)-2
\]
is false for arbitrary graphs \(H\).

## Counterexample

Let
\[
H=2K_1,
\]
the edgeless graph on two vertices.

Its treedepth is
\[
\operatorname{td}(H)=1,
\]
since it is contained in the closure of a rooted forest consisting of two roots of height \(1\).

A graph \(G\) contains \(2K_1\) as a minor if and only if \(|V(G)|\ge 2\):

- If \(G\) has two distinct vertices, delete all other vertices and delete the edge between the selected vertices if it exists. The resulting graph is \(2K_1\).
- Minor operations cannot increase the number of vertices, so a graph with at most one vertex cannot contain \(2K_1\).

Consequently,
\[
\mathcal M_{2K_1}=\{G:|V(G)|\le 1\}.
\]
This class has clustered chromatic number exactly \(1\). Indeed, one color with clustering \(1\) suffices, while \(K_1\in\mathcal M_{2K_1}\) cannot be colored with zero colors. Hence
\[
\chi^*(\mathcal M_{2K_1})=1.
\]
On the other hand,
\[
2\,\operatorname{td}(2K_1)-2=2\cdot1-2=0.
\]
Thus
\[
1=\chi^*(\mathcal M_{2K_1})>0
   =2\,\operatorname{td}(2K_1)-2,
\]
contradicting the extracted statement.

More generally, for every \(r\ge2\),
\[
\operatorname{td}(rK_1)=1,\qquad
\mathcal M_{rK_1}=\{G:|V(G)|\le r-1\},\qquad
\chi^*(\mathcal M_{rK_1})=1.
\]

## Interpretation

The writeup attacks the catalog statement

> For every graph $H$, $\chi^*(\mathcal{M}_H) \leq 2\,\mathrm{td}(H) - 2$

and refutes it "as literally stated" with $H = 2K_1$. The catalog's own notes already
warn: *"PDF source — math notation partially garbled; statement reconstructed from
context."* I fetched the actual arXiv v2 TeX source of the paper
(arXiv:1708.02370, `ClusteredColouring.arXiv2.tex`). The environment labeled
`tdConjecture` is the **4th** item of the shared theorem/conjecture counter (so it
is indeed "Conjecture 4"), and it reads, verbatim:

```tex
\begin{conj}
\label{tdConjecture}
For every graph $H$,  $$\cchi(\MM_H)\leq 2\ctd(H)-2.$$
\end{conj}
```

with, in the preamble,

```tex
\DeclareMathOperator{\ctd}{\overline{td}}
```

i.e. the conjecture is $\chi^*(\mathcal{M}_H) \le 2\,\overline{\mathrm{td}}(H) - 2$
where $\overline{\mathrm{td}}$ is the **connected tree-depth**: the minimum depth
(max number of *vertices* on a root-to-leaf path) of a single rooted **tree** whose
closure contains $H$ as a subgraph. The paper defines ordinary tree-depth as the
max of $\overline{\mathrm{td}}$ over connected components, notes
$\mathrm{td}(H) = \overline{\mathrm{td}}(H)$ *unless* $H$ has two components both
attaining $\mathrm{td}(H)$, in which case
$\overline{\mathrm{td}}(H) = \mathrm{td}(H) + 1$, and states explicitly: *"We
choose to work with connected tree-depth to avoid this distinction."* The authors
thus deliberately picked the very convention that closes the degenerate loophole
the writeup exploits. The overline on $\overline{\mathrm{td}}$ was evidently lost
in PDF-to-text extraction, producing the garbled catalog statement with plain
$\mathrm{td}$.

Consequently the writeup's formalization is **not** the intended conjecture, and
its own literal reading is not even the literal statement of the source paper. A
reasonable author of arXiv:1708.02370 would emphatically not consider Conjecture 4
resolved: for $H = 2K_1$ we have $\overline{\mathrm{td}}(2K_1) = 2$ (a depth-1
rooted tree is a single vertex; a root with one child has depth 2 and closure
$K_2 \supseteq 2K_1$), so the true bound is $2\cdot 2 - 2 = 2 \ge 1 =
\chi^*(\mathcal{M}_{2K_1})$: the real conjecture *holds* for the writeup's
"counterexample". Likewise for every $rK_1$, $r \ge 2$:
$\overline{\mathrm{td}}(rK_1) = 2$ and $\chi^* = 1 \le 2$. The writeup itself
half-suspects this ("a missing connectedness hypothesis in the reconstructed
catalog statement is plausible") but nonetheless files the verdict "disproved"
with high confidence. This is exactly the "interpretation gaming" failure mode:
refuting a strawman literal reading — here, a reading created by a PDF extraction
artifact — instead of the intended conjecture.
