## Interpretation

The target is the informal conjecture stated in prose at the end of Section 1 of
Fox–Luo–Pham, *On random irregular subgraphs* (arXiv:2207.13651, RSA 2024). I pulled
the paper and confirmed the sentence verbatim:

> "We conjecture that the irregular random subgraph H satisfies Property ∗ with high
> probability for all d = o(n/ log n)."

Property (∗) there is `m(H,k) = (1+o(1)) n/(d+1)` for all `0 ≤ k ≤ d`, in the model
`x(v) ~ U[0,1]` i.i.d., `uv ∈ E(H) ⟺ x(u)+x(v) ≥ 1`, `G` `d`-regular on `n` vertices.

The writeup's Theorem is exactly this: for every sequence of `d`-regular graphs with
`d = o(n/log n)`, w.h.p. `max_{0≤k≤d} |m_k − μ| = o(μ)`, `μ = n/(d+1)`, with estimates
uniform in `G`. No strengthening, no weakening, no strawman. The quantitative form (1),
`max_k |m_k − μ| ≤ C(√((n/d) log n) + log n)` with failure probability `≤ Cn^{-3}` for
`d ≥ 64 log n`, is strictly stronger than what is asked and is the natural sharp form
(the deviation is `o(μ)` precisely when `d log n = o(n)`, i.e. exactly at the
conjectured threshold). Interpretation is fair.

This is a `attacks_retry` target. The prompt contains an earlier `gpt-5.6-sol` attempt
(verdict `partial`) which proved the conjecture only under `χ_f(G) d log n = o(n)`.
Nothing is inherited uncritically: the new writeup reuses only the *shape* of the
earlier argument (read-R Hölder + uniform spacings) and re-states both tools from
scratch in §2. Its novel content is §3 (the half-interval bit decomposition), which
replaces the fractional colouring and removes the `χ_f(G)` loss. I checked §2's two
tools independently rather than crediting them from the earlier attempt. The earlier
attempt's own diagnosis of what was missing (an exponential tail for the residual
`R_k = Σ_v (1{deg=k} − p_{v,k})` for high-chromatic `G`) is genuinely circumvented, not
re-committed: the new argument never needs `R_k` at all, because after exposing the
bits the *random* part of the graph is bipartite for free.

## Caveats

1. **Lemma 2.1 has no proof and no citation.** The stated inequality is Finner's (1992);
   the writeup's sketch is wrong in wording ("adding a constant factor when `q < R`") and
   would not survive a referee. This is the one thing a journal version must fix. It is a
   one-line repair (cite Finner, or Pelekis–Ramon's read-`k` Hölder survey).
2. Constants in (13), (14), (15) are left as "absolute `C_0, C_1, λ_0, λ_1`" with
   `e^λ−1−λ = O(λ²)` waved through. They do exist (I instantiated them: `|η| ≤ 1/8`
   forces `λ_0 ≈ 0.117`, `λ_1 ≈ 0.058` after Cauchy–Schwarz, `C_0 ≈ 100`), but nothing is
   spelled out.
3. `B = n e^{−d/16}` is used both as an additive deviation in (21) and as a probability.
   Both are legitimate but the equation reads as a pun; a careful version would name them
   separately.
4. The `d ≥ 64 log n` / `d < 64 log n` split is exhaustive, but §6 is only *useful* when
   `d ≫ log n` — the writeup says so. §7's `ε_n` is `o(1)` only because `d < 64 log n`
   there; the two regimes must be read together and they are.
5. Edge cases: `d = 0` is handled explicitly; `k = 0` and `k = d` are handled (the
   endpoint spacings, §2.2, are explicitly included — the classic off-by-one trap here,
   and it is closed); `G` disconnected or with multiple components is irrelevant since
   nothing beyond `d`-regularity is used; graphs are finite simple undirected, as the
   verdict caveat says. The measure-zero event `x(u)+x(v) = 1` is correctly dismissed.
6. Nothing in the argument requires `G` to be connected, vertex-transitive, or of any
   particular chromatic number — the uniformity claim is genuine and is exactly the point.
7. **Contextual caveat the writeup could not know**: Montgomery–Pokrovskiy–Sudakov
   (arXiv:2606.30612, June 2026) settled the Alon–Wei asymptotic conjecture for all
   `d = o(n)` by *modifying* the random subgraph. The present theorem is about the
   unmodified random subgraph and remains open in the literature, but it is now of
   narrower interest than it was when FLP posed it. The `would_publish: true` flag should
   be read in that light.
8. I could not find any error, but I want to record the residual risk honestly: this is a
   short elementary argument that removes eleven logarithms from a Random Structures &
   Algorithms paper. I checked every inequality by re-derivation and every identity
   numerically, and the one step that carries all the power (the conditional independence
   of each side of the random cut, §4) is both structurally verified by brute force and,
   on reflection, simply true — after exposing `1{x(v) ≥ 1/2}`, monochromatic edges are
   deterministic, so the surviving randomness lives on a bipartite graph. That FLP missed
   it is plausible: their whole paper is committed to a martingale route, and their own
   use of interval indicators is local to Lemma 3.2.

## Referee summary

I set out to break this and could not. The writeup's idea is a single clean move: write
`x(v) = (C_v + U_v)/2` with `C_v` a fair bit, so that after exposing the bits every
low–low edge is absent, every high–high edge is present, and only the cut edges remain
random — which makes the *random* part of the model bipartite for **every** `G`, with no
colouring and hence no `χ_f(G)` loss. Each side is then an independent set for the
random part, so conditioning on one side's labels makes the other side's degree
indicators independent Bernoulli with spacing-distributed parameters, and a read-`d`
Finner/Hölder inequality plus the `Beta(1,r)` mgf gives `m_k` a variance proxy of `n/d`
around the random conditional mean `Q_k(C)`; `Q_k(C)` is in turn a sum of `4/d`-bounded
read-`(d+1)` functions of the bits, so it is sub-Gaussian with the *same* proxy `n/d`;
and `E Q_k = n/(d+1)` exactly. Three pieces, each at scale `√(n/d)`, against a mean
`n/(d+1)` — which is `o(1)` relative precision precisely when `d log n = o(n)`, the
